## 并查集-敏感来源
1. 一旦题目与 连通性/相连/合并为一个集合/求最终的集合数 相关
   - 直接使用 并查集！！！
   - 最后都是求（联通后的） sets数量
2. 很多时候涉及到 二维节点 的 连通性 （岛屿数量问题）
   - 二维转一维 下标变换公式 (x,y) -> [x * 列数 + y]
   - 从一维回推二维(因为 y<列数，如上述供述)  index -> (index / 列数, index % 列数)
3. 一维和二维模板是不同的：
   - 朋友圈是一维的并查集模板
   - NumberOfIslands是二维的并查集模板
