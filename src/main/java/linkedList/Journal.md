## 总结
1. 链表问题一定可以通过增加容器来解决。 数组，栈，队列......
2. 续1：但是链表问题，一般最优解是追求有限个变量的最优解，**即空间复杂度O(1)**
   - 目前看下来，使用容器 与 不使用容器的 时间复杂度都是一样的。因为链表一定是要遍历的，一般就是O(N)
   - 所以最优解，一般都是只关注空间复杂度 -> O(1)
3. 不确定头节点的问题中，DummyHead可以考虑。 逻辑想不明白，先做出来，用DummyHead
   - 删除given value  ||   smallerEqualBigger
4. 构建链表一定需要两个变量：head,**tail=head** ，缺一不可。在 链表实现deque，三向分区 和 随机指针复制 中，都涉及了 链表的分割。特别注意：
   - 先说结论：统一在while外面处理，最后的尾节点的next指针即可。前面的在挂链过程中，next指针都自动被修改了。
   - 要点：
       1. 一定要记得清理tail.next指针（=null），不然会 成环/违规修改原链表指针
       2. 续1：按照我的写法，不要在while里面清理tail.next。 因为对于随机指针复制而言，如果没有写的很精细，会错误编码，导致空指针！！！因为指向节点的指针多了，容易乱。
5. 续4：重组链表，最后一定要清理tail.next指针。    三向分区
6. 需要记忆的内容：
   1. midOrUpMid; midOrDownMid; midOrUpMidPre; midOrDownMidPre
   2. 获取一个链表的入环节点完整步骤，可见**大纲7**
7. 双向链表问题，每一步都要**步步惊心**！！！ 一定要注意：
   1. 每次链接 涉及到 next 和 last指针的链接
   2. 每次断连，也是涉及到两个节点 next 和 last指针
   3. 重新整合/重排序，特别注意清理last next 防环。 例如快排，涉及到三向分区 分割和整合。  分割时三个分区都要注意清理head, tail的前后指针。 整合时注意 链接的两个指针调节 以及 连接后的 首尾指针的next last清理
8. 无环链表的相交节点：【超级错误点】ListNode long 是完全错误的！！！ 不能把关键字作为变量名！！！
## 大纲
1. 单链表反转/双链表反转：
    - 【solution】单独设定pre,cur,next变量
2. 删除value节点
   - 【重点】
     - 可能换头
     - 删除一个节点一定需要preNode； 不需要preNode花招那个，cur.value = cur.next.value，然后删除cur.next节点，只是小trick。生产上会有问题，最根本还是要删除内存地址
   - 【Solution】
     - 1. 不用dummyHead，先处理头，在处理后面
     - 2. DummyHead，所有节点可以统一处理
3. 快慢指针确定： 其实只需要记前两个。后两个的话，只需要slow 提前一个。  可以拿4个节点举例子即可。
   - 中或上中:         slow = head.next, fast = head.next.next
   - 中或下中:         slow = head.next, fast = head.next
   - 中或上中 的前一个: slow = head, fast = head.next.next
   - 中或下中 的前一个: slow = head, fast = head.next
   - 核心代码
   ```java
    //核心代码都是
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ```
4. 【易错，需要回看，避免NPE，起始点必须保证非null，中或下中，快慢指针】是否是回文链表：https://leetcode.cn/problems/aMhZSa/description/
    - 多重解法with different 空间复杂度：
      - (1) O(N)
      - (2) O(N/2) 中和下中，压栈
      - (3) 面试解： O(1)  中和下中，链表反转， l r双指针比较。 
        - 注意：脑海中形成反转后的链表，这样可以算清边界
        - 记得最后一定要恢复反转
5. 将链表分为小中大三部分（链表三向分区）:
   - 【Solution】而且1方法无稳定性，2方法有稳定性
     - 1. 荷兰国旗，空间复杂度O(N)，解法不好
     - 2. 6个指针，空间O(1): 分成小中大三个list，总共六个首尾指针，最后进行整合
       - 难点在于整合： 我选择使用 dummyHead + finalTail 两个变量组织整合链,用finalTail.next连接区间链
       - **【特别是错误点】**在于最后finalTail.next记得置空！！！  要清理指针的
6. CopyListWithRandom：
   - 【Solution】
     - 1. 空间O(N), 哈希表<原始节点，复制节点>
     - 2. 空间O(1), 原始节点1 ->  复制节点1 -> 原始节点2 -> 复制节点2 -> null  链上添加，拆链
7. 给出任意两个链表头节点，返回第一个相交节点 (允许每个链表带环)
   - 涉及以下技巧：
     - 找到链表第一个入环节点，如果无环，返回null - https://leetcode.cn/problems/c32eOV/
     - 如果两个链表都无环，返回第一个相交节点，如果不想交，返回null - https://leetcode.cn/problems/3u1WK4/description/
     - 两个有环链表，返回第一个相交节点，如果不想交返回null
   - 步骤
       - 【0】获得链表第一个入环节点（无则返回null）： 快慢指针 O(1)额外空间复杂度，快慢指针一起走第一次相遇时停止（midOrUpMid初始化slow,fast）。然后slow不动，fast重置为head。此时slow,fast全部步长为1，第一个相遇节点即为相交节点。 O(N)方法-hashset
       - 【1】两个无环链表相交节点： O(1)额外空间复杂度，通过两个链表最后一个节点判断是否存在相交。有的话，先走长链表多余部分，然后长短链表一起走，第一个相同节点即是相交节点
       - 【2】两个有环链表相交节点 ： 四种情况考虑：
           - （1）相交节点在非环部分
           - （2）相交节点在同一个入环节点（12可合并）
           - （3）两个链表的入环节点都在环上，但不同位置
           - （4）无相交节点
       - 【3】一个有环链表与一个无环链表不可能相交
