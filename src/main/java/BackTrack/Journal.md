# 回溯算法核心定义与要点汇总

## 一、核心定义
回溯算法是一种**系统性的深度优先搜索策略**，用于解决**约束满足问题**。它通过逐步构建候选解，并在发现当前部分解不可能导向最终有效解时，立即**回退到上一步**尝试其他可能性，从而避免无效的穷举搜索。

## 二、算法本质
- **核心思想**："试探" + "回退"
- **搜索方式**：深度优先搜索
- **关键优化**：**剪枝** - 提前终止不可能成功的搜索路径
- **别称**：有剪枝的、系统性的深度优先搜索

## 三、算法框架（通用模板）
```java
void backtrack(状态, 选择列表, 路径, 结果集) {
    if (满足结束条件) {
        结果集.add(新路径副本); // 记录一个解
        return;
    }
    
    for (选择 : 当前可用的选择列表) {
        if (当前选择不合法) { // 剪枝条件
            continue;
        }
        
        // 做选择
        路径.add(选择);
        更新状态;
        
        // 递归进入下一层决策树
        backtrack(状态, 选择列表, 路径, 结果集);
        
        // 撤销选择（回溯）
        路径.remove(路径.size() - 1);
        恢复状态;
    }
}
```

## 四、回溯三要素
1. **路径**：已经做出的选择
2. **选择列表**：当前可以做的选择
3. **结束条件**：到达决策树底层，无法再做选择的条件

## 五、典型应用场景
1. **排列组合**：全排列、组合、子集
2. **棋盘问题**：N皇后、数独
3. **分割问题**：分割回文串
4. **寻路决策**：迷宫问题、图着色
5. **括号生成**：生成所有有效的括号组合

## 六、与全排列的关系
- **全排列**是回溯的**典型应用**，但不是回溯的全部
- 回溯是**算法框架**，全排列是**具体问题**
- 回溯可以解决全排列，还能解决众多其他约束满足问题

## 七、时间空间复杂度
- **时间复杂度**：通常为 O(branch_factor^depth) 或 O(n!)，具体取决于问题
    - 全排列：O(n × n!) - n! 个解，每个解需 O(n) 构造
- **空间复杂度**：
    - 递归栈：O(n)
    - 状态存储：O(n) 到 O(n²)
    - 结果存储：O(解的数量 × 解的大小)

## 八、关键要点总结
1. **状态管理**：必须精确管理递归过程中的状态变化
2. **剪枝优化**：尽早识别无效路径是提升效率的关键
3. **回溯操作**：每个选择后必须有对应的撤销操作
4. **结果保存**：保存结果时需创建副本，防止后续修改
5. **终止条件**：必须有明确的结束条件，避免无限递归

## 九、回溯与相关算法对比
| 算法 | 特点 | 适用场景 |
|------|------|----------|
| **回溯** | 系统试错 + 剪枝 | 约束满足、组合优化 |
| **DFS** | 深度优先遍历 | 图/树遍历、连通性 |
| **BFS** | 广度优先遍历 | 最短路径、层级遍历 |
| **DP** | 重叠子问题、最优子结构 | 最优化问题 |

## 十、记忆要点
- **回溯 ≈ DFS + 剪枝**
- 核心操作：**选择 → 递归 → 撤销选择**
- 本质是**遍历决策树**的所有可能路径
- 效率提升靠**剪枝**，避免无效搜索
- 必须**恢复状态**，保证回溯的正确性
