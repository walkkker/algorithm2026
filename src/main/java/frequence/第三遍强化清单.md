## 怎么做第三遍

1. A类每次2至3道，先不看本表错误原因、原代码和标准答案；先读题并写状态/不变量或递归契约。
2. 独立实现，自己列出至少一个能触发历史错误的最小反例，再运行LeetCode或对照测试。
3. B类先做5至10分钟的定点默写/反例解释；解释不清、仍犯旧错或需要提示，就升级为完整重写。
4. C类口述即可；发现忘记模型再升级。D类只抽查，不从头按顺序重做。
5. 本轮通过不删除旧TODO；在下表状态格记录日期、是否看提示、是否复发旧错。3至7天后脱离答案再测一次。
6. “稳定”标准：能独立推导、代码通过、能解释历史错误、能处理反例、能说清复杂度；不是背出标准代码。

不要强求一次完成73道Hot100 A/B：**先做27道A；46道B只有验证失败的才完整重写。**
