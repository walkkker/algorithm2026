# 字符串解码

对应题目：[Q394_DecodeString.java](./Q394_DecodeString.java)

## 核心结论

本题真正的难点不是栈的基本操作，而是：

> 进入嵌套括号时保存外层状态，完成当前括号层后恢复外层状态。

例如：

```text
3[a2[c]]
```

处理内层 `2[c]` 时，不能丢失外层已经生成的 `"a"` 和外层重复次数 `3`。

因此需要保存两类现场：

```text
countStack：进入当前层之前的重复次数
stringStack：进入当前层之前已经生成的外层字符串
```

当前正在处理的括号层由两个变量表示：

```text
count：当前正在读取的重复次数
current：当前括号层已经解码完成的字符串
```

## 核心不变量

> `current` 始终表示当前括号层已经解码完成的内容；两个栈保存进入当前层之前的外层现场。

显式栈与递归调用栈的对应关系：

```text
遇到 '['：保存现场，进入下一层
遇到 ']'：当前层返回，恢复上一层现场
```

所以本题可以理解为使用显式栈模拟递归调用过程。

## 四类字符的处理规则

### 1. 数字

重复次数可能是多位数：

```text
12[a]
```

必须逐位累计：

```java
count = count * 10 + (c - '0');
```

不能直接写成：

```java
count = c - '0';
```

否则 `12` 最终只会得到 `2`。

### 2. 普通字母

字母属于当前括号层，直接追加：

```java
current.append(c);
```

### 3. 左括号

遇到 `[` 表示即将进入新的嵌套层：

```java
countStack.push(count);
stringStack.push(current);

count = 0;
current = new StringBuilder();
```

必须同时完成两件事：

1. 保存外层的重复次数和字符串。
2. 重置当前层状态，开始构造括号内部的新字符串。

### 4. 右括号

遇到 `]` 表示当前层已经完成：

```java
int repeat = countStack.pop();
StringBuilder outer = stringStack.pop();

for (int i = 0; i < repeat; i++) {
    outer.append(current);
}

current = outer;
```

执行顺序是：

1. 取出当前层需要重复的次数。
2. 取出进入当前层之前的外层字符串。
3. 将当前层内容重复追加到外层。
4. 恢复外层，使它重新成为新的 `current`。

## 推演示例

输入：

```text
3[a2[c]]
```

### 读取 `3[`

```text
countStack  = [3]
stringStack = [""]
current     = ""
```

外层重复次数和外层空字符串已经保存，开始处理第一层括号。

### 读取 `a2[`

```text
countStack  = [2, 3]
stringStack = ["a", ""]
current     = ""
```

保存第一层已经生成的 `"a"`，开始处理第二层括号。

### 读取 `c]`

当前层内容为 `"c"`，重复两次后恢复第一层：

```text
current = "a" + 2 * "c"
        = "acc"
```

### 读取最后一个 `]`

将 `"acc"` 重复三次并恢复最外层：

```text
current = "" + 3 * "acc"
        = "accaccacc"
```

## 标准最优解

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {

    public String decodeString(String s) {
        char[] chs = s.toCharArray();

        Deque<Integer> countStack = new ArrayDeque<>();
        Deque<StringBuilder> stringStack = new ArrayDeque<>();

        int count = 0;
        StringBuilder current = new StringBuilder();

        for (char c : chs) {
            if (c >= '0' && c <= '9') {
                // 重复次数可能是多位数。
                count = count * 10 + (c - '0');
            } else if (c == '[') {
                // 保存进入当前括号层之前的外层现场。
                countStack.push(count);
                stringStack.push(current);

                // 开始处理括号内部的新层。
                count = 0;
                current = new StringBuilder();
            } else if (c == ']') {
                // 当前层结束，将当前层结果合并回外层。
                int repeat = countStack.pop();
                StringBuilder outer = stringStack.pop();

                for (int i = 0; i < repeat; i++) {
                    outer.append(current);
                }

                current = outer;
            } else {
                current.append(c);
            }
        }

        return current.toString();
    }
}
```

## 易错点

| 易错点 | 结果与修正 |
|---|---|
| 数字直接覆盖 `count` | 无法处理多位数，必须使用 `count = count * 10 + digit` |
| 遇到 `[` 只保存重复次数 | 完成内层后无法恢复外层字符串 |
| 保存现场后没有重置 `count` | 内层会错误继承外层重复次数 |
| 保存现场后没有创建新的 `current` | 内层与外层内容混在同一个构造器中 |
| 遇到 `]` 后没有执行 `current = outer` | 后续字符仍然追加到已经结束的内层 |
| 只考虑一层括号 | 嵌套结构必须依靠栈或递归保存多层现场 |
| 使用 `Stack` 作为首选容器 | 算法没有错误，但Java中通常优先使用 `Deque` 和 `ArrayDeque` |

## 复杂度

设：

```text
N：编码字符串长度
L：最终解码字符串长度
D：最大括号嵌套深度
```

每个输入字符被扫描一次，生成的每个输出字符都需要被写入结果：

```text
时间复杂度：O(N + L)，通常简写为O(L)
空间复杂度：O(L + D)
```

最终字符串本身可能远大于编码字符串，因此不能只按照输入长度 `N` 描述时间和空间开销。
