## Q20 ValidParentheses 【Hot 100】

### 核心思想与题目要求

20. 有效的括号
给定一个只包含字符`'('、')'、'{'、'`'、'['、']'}的字符串`s`，
判断字符串是否有效。
有效字符串必须满足：左括号必须使用相同类型的右括号闭合，左括号必须按照正确顺序闭合，
并且每个右括号都有对应的同类型左括号。
**核心思路：**左括号入栈；遇到右括号时，先检查栈是否为空，再检查它是否与栈顶匹配。
扫描结束后栈必须为空，否则仍有未闭合的左括号。时间复杂度`O(N)`，空间复杂度
`O(N)`。

### 2026-09-14复盘：先按左右括号分类

这道题最清晰的建模方式，是先判断当前字符属于哪一类，再分别规定行为。

**右括号：只触发匹配和出栈，绝不进栈。**

1. 栈非空并且当前右括号等于栈顶，执行`pop()`；
2. 栈为空或者类型不匹配，当前前缀已经无效，立即返回`false`。

右括号不能入栈，因为右括号出现时必须立即闭合最近一个尚未闭合的左括号。匹配失败后，
后续再出现任何字符都无法修复当前顺序。

**左括号：只负责压入将来期望出现的右括号。**

~~~java
'(' -> push(')')
'[' -> push(']')
'{' -> push('}')
~~~

这样栈内保存的不是已经读取的左括号，而是：

> 所有尚未闭合的左括号，将来按照什么顺序等待右括号与它们匹配。

栈顶就是下一次允许出现的右括号，因此遇到右括号后只需要判断：

~~~java
!stack.isEmpty() && stack.peek() == current
~~~

不再需要编写三组“左括号与右括号的对应关系”。

### 两类失败情况

~~~text
扫描过程中匹配失败：右括号多余或者类型错误，立即返回false。
扫描结束后栈不为空：左括号多余，返回false。
~~~

所以最终不能无条件返回`true`，必须返回：

~~~java
return stack.isEmpty();
~~~

这版分类思路正确且清晰，时间复杂度为`O(N)`，额外空间复杂度为`O(N)`。使用`Stack`不影响
正确性；现代Java可使用`Deque<Character>`替代，但属于容器API优化，不是算法修正。

### 算法流程与正确性依据

1. 根据题意确定输入中可利用的单调性、值域、结构关系或可复用子问题。
2. 使用本专题模型组织状态：入栈前明确栈内单调性或语法层级；弹栈时确定当前元素、左边界和右边界各自角色。
3. 每次更新后维持上述定义；只有在不变量仍成立时才移动指针、覆盖数据或进入下一状态。
4. 最终从定义直接读取答案，而不是根据样例猜测返回位置。

正确性的关键是：每一步只排除已经证明不可能成为答案的选择，或者完整枚举状态定义允许的所有前驱，因此不会漏解。

### 标准 Java 代码

```java
package frequence.Stack;

import java.util.Stack;

/**
 * 20. 有效的括号
 *
 * <p>给定一个只包含字符{@code '('、')'、'{'、'}'、'['、']'}的字符串{@code s}，
 * 判断字符串是否有效。
 *
 * <p>有效字符串必须满足：左括号必须使用相同类型的右括号闭合，左括号必须按照正确顺序闭合，
 * 并且每个右括号都有对应的同类型左括号。
 *
 * <p><b>核心思路：</b>左括号入栈；遇到右括号时，先检查栈是否为空，再检查它是否与栈顶匹配。
 * 扫描结束后栈必须为空，否则仍有未闭合的左括号。时间复杂度{@code O(N)}，空间复杂度
 * {@code O(N)}。
 */
public class Q20_ValidParentheses {

    public boolean isValid(String s) {
        char[] chs = s.toCharArray();
        Stack<Character> stack = new Stack<>();
        for (int i = 0; i < chs.length; i++) {
            if (chs[i] == '(' || chs[i] == '{' || chs[i] == '[') {
                stack.push(chs[i]);
            } else {
                if (stack.isEmpty()) {
                    return false;
                } else {
                    if ((chs[i] == ')' && stack.peek() != '(')
                            || (chs[i] == ']' && stack.peek() != '[')
                            || (chs[i] == '}' && stack.peek() != '{')) {
                        return false;
                    } else {
                        stack.pop();
                    }
                }
            }
        }
        return stack.isEmpty();
    }
}
```

- 不要在没有写清状态、区间或返回值定义前直接套模板。
- 边界条件必须与主循环使用同一套下标语义。

### 复杂度与面试记忆

- 扫描结束后栈必须为空，否则仍有未闭合的左括号。时间复杂度`O(N)`，空间复杂度
- `O(N)`。

> 记忆模板：入栈前明确栈内单调性或语法层级；弹栈时确定当前元素、左边界和右边界各自角色。

## Q84 LargestRectangleInHistogram 【Hot 100】

### 核心思想与题目要求

84. 柱状图中最大的矩形
给定一个整数数组`heights`，其中`heights[i]`表示柱状图中第`i`根柱子
的高度，每根柱子的宽度为`1`。返回能够在柱状图中勾勒出的最大矩形面积。

单调栈：寻找每根柱子左右两侧最近的严格更小值。

### 2026-09-16复盘：最近更小、相等弹出不结算

你的原始记忆是：

~~~text
最近最小
相等弹出，不考虑
~~~

更精确的模型是：对于每个被结算的柱子`popIndex`，寻找：

~~~text
left  = 左侧最近的严格更小下标
right = 右侧最近的严格更小下标
~~~

那么以`heights[popIndex]`为高的最大矩形只能覆盖开区间`(left,right)`：

~~~java
width = right - left - 1;
area = width * heights[popIndex];
~~~

### 弹栈时三个角色不能混淆

~~~java
int popIndex = stack.pop();
int right = i;
int left = stack.isEmpty() ? -1 : stack.peek();
~~~

- `popIndex`：当前正在结算的柱子，提供矩形高度；
- `i`：触发弹栈的位置，提供右侧严格更小边界；
- 弹栈后的`stack.peek()`：提供左侧严格更小边界。

因此必须写成：

~~~java
answer = Math.max(
        answer,
        (right - left - 1) * heights[popIndex]
);
~~~

致命错误是使用当前柱子的高度：

~~~java
// 错误：heights[i]只是触发弹栈的更小值，不是被结算柱子的高度
(right - left - 1) * heights[i]
~~~

### 为什么相等弹出但不结算

当前实现使用：

~~~java
while (!stack.isEmpty()
        && heights[i] <= heights[stack.peek()]) {
    int popIndex = stack.pop();

    if (heights[i] < heights[popIndex]) {
        // 只有严格更小时才结算
    }
}
~~~

当`heights[i] == heights[popIndex]`时：

1. 当前`i`不是右侧严格更小边界，所以不能结算旧下标；
2. 弹出旧下标，保留更靠右的等高下标`i`；
3. 新下标能够继承弹栈后更远的左边界；
4. 等以后出现严格更小值，或者扫描结束，再统一计算整个等高平台的最大宽度。

例如：

~~~text
heights = [2,2]

i=1时弹出下标0，但不结算；然后压入下标1。
扫描结束后，下标1的左边界是-1、右边界是2：
面积 = (2 - (-1) - 1) * 2 = 4
~~~

因此“相等弹出、不考虑”不会漏答案，而是在等高柱中只保留一个最终代表。

### 数组结束后的虚拟右边界

扫描结束后仍在栈中的柱子，说明右侧没有严格更小值，统一令：

~~~java
right = heights.length;
~~~

左侧没有更小值时统一令：

~~~java
left = -1;
~~~

每个下标最多入栈一次、出栈一次，时间复杂度为`O(N)`，额外空间复杂度为`O(N)`。

### 标准 Java 代码

```java
package frequence.Stack;

import java.util.*;

/**
 * 84. 柱状图中最大的矩形
 *
 * <p>给定一个整数数组{@code heights}，其中{@code heights[i]}表示柱状图中第{@code i}根柱子
 * 的高度，每根柱子的宽度为{@code 1}。返回能够在柱状图中勾勒出的最大矩形面积。
 */
public class Q84_LargestRectangleInHistogram {
    /**
     * 单调栈： 找最近较小
     */
    public int largestRectangleArea(int[] heights) {
        Stack<Integer> stack = new Stack<>();
        int ans = 0;
        for (int i = 0; i < heights.length; i++) {
            while (!stack.isEmpty() && heights[i] <= heights[stack.peek()]) {
                int popIndex = stack.pop();
                if (heights[i] < heights[popIndex]) {
                    int l = stack.isEmpty() ? -1 : stack.peek();
                    int r = i;
                    ans = Math.max(ans, (r - l - 1) * heights[popIndex]);
                }
            }
            stack.push(i);
        }

        while (!stack.isEmpty()) {
            int popIndex = stack.pop();
            int l = stack.isEmpty() ? -1 : stack.peek();
            int r = heights.length;
            ans = Math.max(ans, (r - l - 1) * heights[popIndex]);
        }
        return ans;
    }
}
```

```java
package frequence.Stack;

import java.util.Stack;

/**
 * 155. 最小栈
 *
 * <p>设计一个支持{@code push、pop、top}操作，并能在常数时间内检索最小元素的栈。
 *
 * <p>{@code push、pop、top、getMin}操作都必须具有{@code O(1)}时间复杂度。
 *
 * <p><b>核心思路：</b>{@code stack1}保存完整数据，{@code stack2}只保存各阶段的最小值。
 * 新值小于或等于当前最小值时才进入{@code stack2}；弹出值等于当前最小值时，两个栈同步弹出。
 *
 * <p><b>注意：</b>新值与最小值相等时也必须压入辅助栈，否则弹出一个重复最小值后会过早丢失
 * 当前最小值。
 */
public class Q155_MinStack {

    public static class MinStack {

        private final Stack<Integer> stack1;
        private final Stack<Integer> stack2;

        public MinStack() {
            stack1 = new Stack<>();
            stack2 = new Stack<>();
        }

        public void push(int value) {
            stack1.push(value);
            if (stack2.isEmpty()) {
                stack2.push(value);
            } else {
                if (value <= stack2.peek()) {
                    stack2.push(value);
                }
            }
        }

        public void pop() {
            int popValue = stack1.pop();
            if (popValue == stack2.peek()) {
                stack2.pop();
            }
        }

        public int top() {
            return stack1.peek();
        }

        public int getMin() {
            return stack2.peek();
        }
    }
}
```

```java
               int repeat = countStack.pop();
               StringBuilder outer = stack.pop();

                for (int time = 0; time < repeat; time++) {

               }
               // TODO: 【不能遗漏】合并完成后必须让current重新指向outer；
               // 后续字符属于恢复后的外层，而不是已经结束的内层。
               current = outer;
           } else {
               // 普通字母属于当前括号层，直接追加。
               current.append(chs[i]);
           }
       }
       return current.toString();
    }
}
```

### 核心思想与题目要求

739. 每日温度
给定一个整数数组`temperatures`表示每天的温度，返回数组`answer`，其中
`answer[i]`表示第`i`天之后需要等待多少天才能出现更高温度。如果之后不会出现
更高温度，则该位置返回`0`。

TODO: 【概念修正】本题不是寻找“右侧最近最大”，而是寻找：

> 右侧第一个严格大于当前温度的位置，并计算两个位置之间的下标距离。

“第一个”和“最大”是不同目标。例如右侧依次出现`75、80`，只要`75`已经高于当前温度，
答案就是`75`的位置，不需要继续寻找更大的`80`。

你的原始记忆“最近最大，相等不弹出”可以保留，但应精确解释为：

~~~text
最近最大     -> 右侧最近的严格更大值，不是右侧范围内的最大值
相等不弹出   -> 完全正确，相等温度不满足题目的“更高”要求
~~~

### 2026-09-16复盘：栈内到底保存什么

栈中保存的是：

> 还没有找到右侧更高温度的日期下标。

必须保存下标而不是温度值，因为解题同时需要完成两项操作：

~~~text
temperatures[stack.peek()]：比较温度
currentIndex - poppedIndex：计算等待天数
~~~

从栈底到栈顶：

~~~text
下标严格递增
对应温度单调不升
~~~

相等温度不能弹出，因为题目要求后一天的温度“严格更高”。

### 为什么当前i是右侧第一个更高位置

数组从左向右扫描。对于仍在栈中的下标`popIndex`，从它入栈到当前`i`之前，没有任何温度
严格大于`temperatures[popIndex]`，否则它已经在更早的位置弹栈。

所以第一次满足：

~~~java
temperatures[i] > temperatures[stack.peek()]
~~~

当前`i`就必然是栈顶下标右侧第一个更高温度的位置。

### 答案保存距离，不保存目标下标

~~~java
// 错误：记录了更高温度的日期下标
answer[popIndex] = i;

// 正确：记录还需要等待几天
answer[popIndex] = i - popIndex;
~~~

循环结束后仍留在栈中的日期，右侧不存在更高温度，答案保持为0。由于Java的`int[]`默认值
就是0，因此不需要额外清栈赋值；显式清栈并赋0也正确，只是冗余。

每个下标最多入栈一次、出栈一次，所以时间复杂度是`O(N)`，额外空间复杂度是`O(N)`。

```java
package frequence.Stack;

import java.util.*;

/**
 * 739. 每日温度
 *
 * <p>给定一个整数数组{@code temperatures}表示每天的温度，返回数组{@code answer}，其中
 * {@code answer[i]}表示第{@code i}天之后需要等待多少天才能出现更高温度。如果之后不会出现
 * 更高温度，则该位置返回{@code 0}。
 */
public class Q739_DailyTemperatures {

    /**
     * 寻找右侧较大。
     * @param temperatures
     * @return
     */

    /**
     找右侧最近最大。
     单调栈。
     */
    class Solution {
        public int[] dailyTemperatures(int[] temperatures) {
            int len = temperatures.length;
            int[] ans = new int[len];
            Stack<Integer> stack = new Stack<>();
            for (int i = 0; i < len; i++) {
                while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                    int popIndex = stack.pop();
                    ans[popIndex] = i - popIndex;
                }
                // TODO: 【错误】单调栈/滑动窗口双端队列 里面存的都是下标
                // 错误行： stack.push(temperatures[i]);
                stack.push(i);
            }
            return ans;
        }
    }
}
```
