# 原地哈希解题手册

## 1. 定义

原地哈希是指：

> 不创建额外的 `HashSet` 或 `HashMap`，而是利用输入数组的下标作为哈希槽，
> 通过交换、正负号或固定偏移量记录某个数字是否出现。

普通哈希表：

```java
set.add(x);
set.contains(x);
```

原地哈希：

```text
数字x -> 数组中的固定下标
```

例如数组长度为 `N`，有效值域为 `[1,N]`：

```text
数字1 -> 下标0
数字2 -> 下标1
...
数字x -> 下标x-1
...
数字N -> 下标N-1
```

映射函数就是：

```text
index(x) = x - 1
```

## 2. 识别条件

同时出现下面这些条件时，应当考虑原地哈希：

```text
1. 数组长度为N。
2. 关键值域是[1,N]或[0,N-1]。
3. 每个有效值都能映射到唯一合法下标。
4. 题目询问缺失、重复、存在性或有限次数统计。
5. 允许修改输入数组，不要求保留原始顺序。
6. 要求O(N)时间和O(1)额外空间。
```

常见提示语：

```text
1 <= nums[i] <= N
数字都位于[0,N]中
找出缺失数字
找出重复数字
不使用额外空间
```

## 3. 值域与下标映射

| 有效值域 | 常用映射 |
|---|---|
| `[1,N]` | `x -> x-1` |
| `[0,N-1]` | `x -> x` |
| `[0,N]` | `x -> x`，但数组只有 N 个位置，需要单独处理值 N |

Q41 的输入值域可能包含负数和大数，但答案只可能在 `[1,N+1]`，所以真正需要归位的值仍然只有 `[1,N]`。

## 4. 模板一：交换归位

目标是让每个有效数字回到自己的位置：

```text
nums[i] = x  应该放到  nums[x-1]
```

通用骨架：

```java
for (int i = 0; i < nums.length; i++) {
    while (nums[i] >= 1
            && nums[i] <= nums.length
            && nums[i] != nums[nums[i] - 1]) {

        swap(nums, i, nums[i] - 1);
    }
}
```

整理完成后：

```java
for (int i = 0; i < nums.length; i++) {
    if (nums[i] != i + 1) {
        // 数字i+1没有出现在数组中
    }
}
```

### 为什么必须使用 while

交换后，当前位置 `i` 得到了一个新数字。这个新数字可能仍然需要归位，因此不能立即进入下一个下标。

例如：

```text
[3,4,-1,1]

i=0，数字3应该去下标2：
[-1,4,3,1]

下标0换入-1，需要重新判断它是否有效，而不是假设下标0已经处理完成。
```

### 为什么必须检查目标位置

条件：

```java
nums[i] != nums[nums[i] - 1]
```

用于处理重复值。

例如：

```text
[1,1]
```

第二个 `1` 的目标位置已经存放 `1`。如果继续交换，相同数字会被无限交换，形成死循环。

## 5. 模板二：正负号标记

如果所有有效数字都位于 `[1,N]`，可以使用目标位置的正负号记录数字是否出现：

```java
for (int i = 0; i < nums.length; i++) {
    int value = Math.abs(nums[i]);
    int index = value - 1;

    nums[index] = -Math.abs(nums[index]);
}
```

标记含义：

```text
nums[x-1] < 0：数字x出现过
nums[x-1] > 0：数字x没有出现
```

最后检查：

```java
for (int i = 0; i < nums.length; i++) {
    if (nums[i] > 0) {
        // 数字i+1没有出现
    }
}
```

正负号标记的前提更严格：

```text
1. 数组值能够安全转换为合法下标。
2. 0、负数和越界值需要提前处理。
3. 题目只要求存在性，不要求把数字真正归位。
```

## 6. 两种方式如何选择

| 方式 | 特点 | 适用场景 |
|---|---|---|
| 交换归位 | 数字回到唯一目标位置 | 缺失值、重复值、排列恢复 |
| 正负号标记 | 只记录数字是否出现 | 找消失数字、找重复数字 |

交换归位更直观地体现：

```text
数字x应该位于下标x-1
```

正负号标记通常代码更短，但需要确保取绝对值后一定能映射到合法下标。

## 7. 为什么是 O(N)

交换归位代码虽然包含 `for + while`，但不是 `O(N^2)`。

每次有效交换都会让至少一个数字进入自己的最终目标位置：

```text
数字x -> 下标x-1
```

数组只有 `N` 个位置，所以成功归位次数最多为 `N`。外层指针也只移动 `N` 次，因此：

```text
时间复杂度：O(N)
额外空间复杂度：O(1)
```

正负号标记中，每个元素只处理一次，同样是：

```text
时间复杂度：O(N)
额外空间复杂度：O(1)
```

## 8. 高频错误

### 8.1 交换后立即移动 i

```java
swap(nums, i, target);
i++; // 错误：换到i的新数字还没有处理
```

交换后应该继续检查当前位置。

### 8.2 没有处理重复值

```java
while (nums[i]在有效范围) {
    swap(nums, i, nums[i] - 1);
}
```

重复数字可能导致死循环。必须检查目标位置是否已经存在相同数字。

### 8.3 越界值直接作为下标

使用：

```java
nums[nums[i] - 1]
```

之前必须保证：

```java
1 <= nums[i] <= N
```

### 8.4 忘记算法会破坏输入

原地哈希会改变：

- 元素顺序
- 元素正负号
- 部分位置的原始值

如果题目禁止修改输入，不能直接使用该方法。

### 8.5 把任意大值域强行映射到下标

如果所有 `[-10^9,10^9]` 范围内的值都重要，而数组长度只有 `N`，就不存在直接的一一映射。

此时应考虑：

- `HashSet` 或 `HashMap`
- 排序
- 坐标压缩
- 其他数据结构

## 9. Q41 示例

```text
输入：[3,4,-1,1]
```

归位目标：

```text
1 -> 下标0
3 -> 下标2
4 -> 下标3
-1不在[1,N]，忽略
```

整理后：

```text
[1,-1,3,4]
```

从左到右检查：

```text
下标0保存1：正确
下标1没有保存2：第一个缺失正数是2
```

## 11. 面试表达

可以这样说明：

> 数组长度为 N，而真正关心的值域是 `[1,N]`，因此可以建立 `x -> x-1`
> 的一一映射，把输入数组本身当作哈希表。将每个有效数字交换到目标下标，
> 重复值通过检查目标位置避免死循环。归位后，第一个不满足
> `nums[i] == i+1` 的位置就是答案。每次交换都会归位至少一个数字，
> 所以总时间复杂度为 `O(N)`，额外空间复杂度为 `O(1)`。

最终记忆：

> 有限值域与数组下标能够一一映射，并且允许修改输入时，考虑原地哈希。
