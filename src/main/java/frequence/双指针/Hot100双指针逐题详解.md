# Hot 100 双指针逐题详解

> 本文按项目现有package整理。`【Hot 100】`是主线题，`【扩展】`是同模型扩展题。

## 专题核心

两个指针共同缩小搜索空间，关键是证明每次移动排除的区域不可能包含答案。

**统一记忆：** 排序或单调性提供移动方向；固定一侧、移动另一侧；收集答案后处理重复值。

        List<List<Integer>> ans = new ArrayList<>();

        Arrays.sort(nums);

        for (int i = 0; i < nums.length - 2; i++) {

                        left++;
