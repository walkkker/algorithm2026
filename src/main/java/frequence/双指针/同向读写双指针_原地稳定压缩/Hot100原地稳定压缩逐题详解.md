## Q26 RemoveDuplicatesFromSortedArray 【扩展】

### 核心思想与题目要求

LeetCode 26：删除有序数组中的重复项。
DONE: 【已独立完成】LeetCode最新AC提交：743171495。
每种数字只保留一个，并返回去重后的有效长度。
返回后只保证 `[0, 返回长度)` 是有效结果。
**有序是关键前提：**相同数字在有序数组中必然连续，
所以当前元素只需要和“最后一个已经保留的元素”比较。
**模型：快慢指针 + 原地稳定压缩。**
`fast` 寻找新的数字，`slow` 指向下一个新数字的写入位置。
循环不变量是：
{@code
[0, slow) 保存已经扫描部分的全部不同数字，并且保持升序。
nums[slow - 1] 是最后一个已经保留的数字。
}
是否保留当前元素依赖的是压缩结果`nums[slow - 1]`，而不是无效区域中的残留值。
`[slow, fast)`可能仍保存旧数据，但它已经不属于有效结果，不能参与去重判断。
例如 `[0, 0, 1, 1, 1, 2]`：
{@code
第一个 0 直接保留
后续 0 与最后保留值相同：跳过
遇到 1，与最后保留值 0 不同：写入 slow 位置
后续 1 跳过；遇到 2 时写入 slow 位置
返回 3，有效区间为 [0, 1, 2]
}
时间复杂度为 O(N)，额外空间复杂度为 O(1)。

用户在LeetCode独立完成的AC版本。

### 算法流程与正确性依据

1. 根据题意确定输入中可利用的单调性、值域、结构关系或可复用子问题。
2. 使用本专题模型组织状态：始终定义[0,write)的含义；覆盖前证明write不会越过尚未读取的位置。
3. 每次更新后维持上述定义；只有在不变量仍成立时才移动指针、覆盖数据或进入下一状态。
4. 最终从定义直接读取答案，而不是根据样例猜测返回位置。

正确性的关键是：每一步只排除已经证明不可能成为答案的选择，或者完整枚举状态定义允许的所有前驱，因此不会漏解。

## Q27 RemoveElement 【扩展】

### 核心思想与题目要求

LeetCode 27：移除元素。

{@code
[0, slow)      已保留元素
[slow, fast)   已检查但不属于有效结果的区域

{@code

fast 遇到 2：写入 nums[0]
fast 遇到 2：写入 nums[1]
fast 遇到 3：丢弃

## Q80 RemoveDuplicatesFromSortedArrayII 【扩展】

### 核心思想与题目要求

LeetCode 80：删除有序数组中的重复项 II。
DONE: 【已独立完成】LeetCode最新AC提交：743171986。
原地修改有序数组，使每个元素最多出现两次，返回有效结果长度。只保证返回后
`[0, 返回长度)` 是有效结果。
**模型：保留条件依赖压缩结果。**`fast` 读取原数组，`slow`
指向下一个写入位置，`[0, slow)` 始终是已经满足“每个值最多出现两次”的结果。
保留当前元素的统一条件是：
{@code
slow < 2 || nums[fast] != nums[slow - 2]
}
当结果不足两个元素时直接保留；否则，如果当前值等于结果中倒数第二个值，由于数组有序，
结果末尾两个值和当前值必然相同，继续写入就会出现第三次。
该结论可以推广为“每个值最多保留 `k` 次”：
{@code
slow < k || nums[fast] != nums[slow - k]
}
这里比较的是压缩结果 `nums[slow - k]`，不是原始输入中的相邻位置。
时间复杂度为 O(N)，额外空间复杂度为 O(1)。

## Q88 MergeSortedArray 【扩展】

### 核心思想与题目要求

LeetCode 88：合并两个有序数组。
DONE: 【已独立完成】LeetCode最新AC提交：743311699。用户版本见`#myMerge`。
`nums1` 的长度为`m + n`，前`m`个位置是有效有序数据，末尾预留
`n`个位置；`nums2`包含`n`个有序元素。要求将结果原地合并到
`nums1`。
**模型：两个输入指针 + 一个反向输出指针。**
`i`和`j`分别读取两个数组的有效末尾，`write`从`nums1`末尾写入。
每次比较两个未处理区间的最大值，将较大者放到结果末尾。
不能直接从前向后写，因为会覆盖`nums1`中尚未读取的有效元素。反向合并利用了
`nums1`末尾的预留空间，不会破坏待处理数据。
主循环只需要保证`nums2`处理完：若`nums1`先耗尽，继续复制
`nums2`；若`nums2`先耗尽，`nums1`剩余元素已经位于正确位置。
时间复杂度为 O(M + N)，额外空间复杂度为 O(1)。

 *

 * {@code n}个位置；{@code nums2}包含{@code n}个有序元素。要求将结果原地合并到
 * {@code nums1}。

 * {@code i}和{@code j}分别读取两个数组的有效末尾，{@code write}从{@code nums1}末尾写入。
 * 每次比较两个未处理区间的最大值，将较大者放到结果末尾。
 *
 * <p>不能直接从前向后写，因为会覆盖{@code nums1}中尚未读取的有效元素。反向合并利用了
 * {@code nums1}末尾的预留空间，不会破坏待处理数据。
 *

 * {@code nums2}；若{@code nums2}先耗尽，{@code nums1}剩余元素已经位于正确位置。
 * 时间复杂度为 O(M + N)，额外空间复杂度为 O(1)。
 */
public class Q88_MergeSortedArray {

    /**
     * 必须从后往前，是因为为了避免覆盖。
     * @param nums1
     * @param m
     * @param nums2
     * @param n
     */
    public void myMerge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1;
        int p2 = n - 1;
        int index = m + n - 1;
        while (p1 >= 0 && p2 >= 0) {
            nums1[index--] = nums1[p1] > nums2[p2] ? nums1[p1--] : nums2[p2--];
        }

        while (p2 >= 0) {
            nums1[index--] = nums2[p2--];
        }
    }



    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int write = m + n - 1;

        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) {
                nums1[write--] = nums1[i--];
            } else {
                nums1[write--] = nums2[j--];
            }
        }
    }
}
