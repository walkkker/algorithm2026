## 核心观察

最长递增子序列、乘积最大子数组、最长有效括号具有两个明显共同点：

1. 从递归或状态推进角度看，主位置参数都只有一个：当前位置 `i`。
2. DP 状态都通过“**必须以 i 位置结尾**”定义，而不是定义成前 `i` 个位置中的全局答案。

- [Q152 乘积最大子数组](./Q152_MaximumProductSubarray.java)

## 为什么强调“必须以 i 结尾”

如果直接定义：

```text
dp[i] = 前i个位置中的全局最优答案
```

状态中只留下一个数，通常无法判断 `nums[i+1]` 能否接在已有方案后面，因为不知道已有最优方案
到底以什么值或什么结构结尾。

定义成：

```text
dp[i] = 必须以i结尾的局部最优答案
```

就固定了方案右边界。转移时只需要研究“哪个前驱可以连接到 i”，全局答案再通过所有结尾状态取最大值：

```java
ans = Math.max(ans, dp[i]);
```

因此，这类题目的通用结构是：

```text
1. 固定右边界i；
2. 枚举或定位合法前驱；
3. 计算必须以i结尾的答案；
4. 使用所有dp[i]更新全局答案。
```

## 三道题的差异

| 题目 | 结尾状态 | 前驱方式 | 特殊点 |
|---|---|---|---|
| Q300 最长递增子序列 | `dp[i]`：以 `nums[i]` 结尾的 LIS 长度 | 枚举所有 `j < i` | 子序列不连续，因此可能连接任意前驱 |
| Q673 最长递增子序列的个数 | `length[i] / count[i]`：以i结尾的最优长度及其方案数 | 枚举所有 `j < i` | 更优时覆盖计数，相同最优时累加计数 |
| Q152 乘积最大子数组 | `maxDp[i] / minDp[i]`：以 `i` 结尾的最大/最小乘积 | 只依赖 `i-1` | 负数使最大值和最小值互相转换 |
| Q32 最长有效括号 | `dp[i]`：以 `i` 结尾的最长有效括号长度 | 根据上一段长度跳到匹配位置 | 只有 `s[i] == ')'` 才可能形成答案 |

共同点是“以 i 结尾”，但转移方式并不相同。

### Q300：枚举所有前驱

```text
dp[i] = 1

如果 j < i 且 nums[j] < nums[i]：
dp[i] = max(dp[i], dp[j] + 1)
```

因为子序列不要求连续，`nums[i]` 可以连接任意更早的合法结尾，所以需要枚举 `j`。

### Q673：结尾型最优值 + 最优方案计数

Q673沿用Q300的结尾状态，但每个位置需要同时保存两个属性：

```text
length[i] = 必须以nums[i]结尾的LIS长度
count[i]  = 达到length[i]的下标子序列数量
```

转移时必须先比较候选长度：

```text
candidate > length[i]：发现更优长度，覆盖length[i]和count[i]
candidate = length[i]：发现同样优的新来源，只累加count[i]
candidate < length[i]：不是最优方案，忽略
```

最后先确定全局最长长度，再累加所有达到该长度的`count[i]`。这里没有增加新的独立状态参数，
状态仍然由i确定；`length/count`只是同一状态的两个属性。

### Q152：连续子数组 + 双状态

连续子数组要求当前元素只能连接 `i-1` 结尾的状态：

```text
maxDp[i] = max(nums[i], maxDp[i-1] * nums[i], minDp[i-1] * nums[i])
minDp[i] = min(nums[i], maxDp[i-1] * nums[i], minDp[i-1] * nums[i])
```

只维护最大值不够，因为：

```text
很小的负数 × 当前负数 = 很大的正数
```

每个状态只依赖前一个位置，因此可以压缩为 `maxEnd`、`minEnd` 两个变量。

### Q32：根据上一段长度跳跃

```text
dp[i] = 必须以右括号i结尾的最长有效括号长度
```

如果 `s[i-1] == '('`，直接形成 `()`；如果 `s[i-1] == ')'`，先跳过 `dp[i-1]` 表示的
完整有效段，再检查更左边是否存在可以匹配当前右括号的 `(`：

```java
int matchingLeft = i - dp[i - 1] - 1;
```

匹配成功后，还要连接 `matchingLeft` 左侧紧邻的有效段。

## 位置结尾型 DP 的转移分类

### 1. 只连接前一个位置

适用于连续子数组或连续子串：

```text
dp[i]只依赖dp[i-1]
```

代表题目：

- Q53 最大子数组和：`dp[i]` 为必须以 `i` 结尾的最大子数组和。
- Q152 乘积最大子数组：同时维护最大、最小结尾乘积。
- Q674 最长连续递增序列：如果 `nums[i] > nums[i-1]`，执行 `dp[i]=dp[i-1]+1`。

这类状态通常可以压缩到 O(1) 额外空间。

### 2. 枚举所有更早的前驱

适用于不要求连续的子序列：

```text
dp[i]依赖若干dp[j]，其中j<i
```

代表题目：

- Q300 最长递增子序列。
- Q376 摆动序列的基础 DP，可定义以 `i` 结尾且最后趋势向上/向下的状态。
- 最长递减子序列：把比较条件反转即可。

朴素时间复杂度通常为 O(N²)。

### 3. 根据已有长度跳到结构边界

状态不一定只看 `i-1`，但可以利用前一状态保存的长度直接跳过一整段结构：

- Q32 最长有效括号。
- 部分字符串匹配、分段和区间拼接问题。

这种题最容易错在：

```text
跳跃后的下标越界；
只连接当前结构，遗漏更左侧相邻的合法结构。
```

### 4. 同一个结尾维护多个状态

一个 `dp[i]` 无法完整描述结尾信息时，需要拆成多个状态：

- Q152：最大乘积、最小乘积。
- Q376：最后一步向上、最后一步向下。
- 股票状态机：第 `i` 天持有股票、不持有股票。

判断标准是：未来转移是否需要区分当前方案的不同结尾属性。

## 统一解题步骤

遇到数组或字符串上的“最长/最大连续段或子序列”问题，可以依次询问：

1. 能否定义“必须以 `i` 结尾”的局部答案？
2. 当前 `i` 可以连接哪些前驱：仅 `i-1`、任意 `j<i`，还是根据已有长度跳跃？
3. 一个状态是否足够，还是需要最大/最小、上升/下降等多状态？
4. `dp[i]` 是最终答案，还是需要对所有 `dp[i]` 取最大值？
5. 如果只依赖固定数量的前驱，能否压缩空间？

## 高频错误

| 错误 | 修正 |
|---|---|
| 把 `dp[i]` 定义成前缀全局最优，却又尝试连接当前元素 | 改成“必须以 i 结尾”，保留右边界信息 |
| 默认答案一定是 `dp[n-1]` | 如果最优方案可以提前结束，需要维护全局最大值 |
| 连续子数组仍枚举所有 `j<i` | 连续模型通常只能连接 `i-1` |
| 子序列只检查 `i-1` | 不连续模型可能需要枚举任意前驱 |
| 乘积问题只维护最大值 | 负数会让最小值转成最大值，必须维护双状态 |
| 状态更新时覆盖了仍要使用的旧值 | 先保存所有候选，再同时更新当前状态 |

## 记忆结论

```text
“以i结尾”不是答案本身，而是为了固定右边界、保留转移所需信息。

连续问题：通常连接i-1；
子序列问题：通常枚举j<i；
结构匹配问题：可能根据已有长度向左跳；
结尾属性不唯一：拆成多个状态。
```
