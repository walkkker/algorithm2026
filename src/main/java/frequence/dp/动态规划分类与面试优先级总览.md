# 动态规划分类与面试优先级总览

## 一、总论：先建立一张统一的 DP 地图

### 1. 动态规划的本质

动态规划不是“填表技巧”，而是对有重复子问题的尝试过程进行状态复用。

面对一道题，最初应该问的是：

```text
1. 我正在解决的子问题是什么？
2. 哪些变化参数能唯一确定这个子问题？
3. 当前状态有哪些选择？
4. 每个选择会进入哪个更小的状态？
5. 多个来源之间是取 max、min、求和，还是逻辑或？
```

例如打家劫舍：

```text
process(i) = 考虑房屋[i..n-1]时能获得的最大金额

选择偷i：nums[i] + process(i + 2)
选择不偷i：process(i + 1)

process(i) = max(nums[i] + process(i + 2), process(i + 1))
```

只有当状态定义、选择和转移都明确后，才应该进入记忆化搜索、严格位置依赖分析和表格 DP。

### 2. DP 必须从三个正交维度分类

一道题不能只用“一维 DP”或“二维 DP”来定位。更精确的分类包含三个维度：

| 分类维度 | 解决的问题 | 典型取值 |
|---|---|---|
| **状态拓扑** | 一个子问题由哪些坐标确定 | 前缀长度、结尾位置、区间左右端点、容量、棋盘坐标、树节点 |
| **状态值语义** | `dp`格子保存什么 | 可行性、最大值、最小值、方案数、最优值+最优方案数 |
| **存储实现** | 逻辑状态最终如何落到代码 | 二维表、一维表、滚动数组、多个一维数组、常数变量 |

例如 Q416 分割等和子集：

```text
状态拓扑：物品前缀 + 目标容量，逻辑上是二维 0-1 背包
状态值：可行性 boolean
存储实现：可以从 boolean[][] 压缩成 boolean[]
```

压缩后只看到一个 `boolean[]`，不代表问题的逻辑状态原本只有一维。

另外，本文中的模型标签不是互斥分组。“状态拓扑”既包含状态坐标如何组织，也包含状态之间如何连接。
同一道题应该同时用多个标签准确定位：

| 题目 | 状态坐标 | 依赖形式 | 状态值语义 |
|---|---|---|---|
| Q70 爬楼梯 | 前缀长度`i` | 固定前驱`i-1/i-2` | 纯计数 |
| Q139 单词拆分 | 前缀长度`end` | 枚举最后分割点`start` | 可行性 |
| Q152 乘积最大子数组 | 强制结尾位置`i` | 只连接`i-1` | 最大/最小数值属性 |
| Q416 分割等和子集 | 物品前缀+容量 | 选或不选当前物品 | 可行性 |
| Q673 LIS个数 | 强制结尾位置`i` | 枚举所有`j<i` | 最优值+最优计数 |

因此，看到一道题同时属于“前缀 DP”和“固定前驱 DP”并不矛盾：前者说明坐标语义，后者说明依赖边的形式。

### 3. 面试优先级总表

下面按“常见程度 + 可迁移价值 + 现场可推导性”分层。越靠前越应该优先掌握。

| 优先级 | 定位 | 建议掌握的模型 |
|---|---|---|
| **第一层：面试必会** | Hot 100、常规中等题高频 | 固定前驱线性 DP、前缀/切分 DP、位置结尾型 DP、棋盘 DP、双序列前缀 DP、基础背包、区间 DP、基础状态机 DP |
| **第二层：中高频进阶** | 中等偏难，掌握后区分度较高 | 计数 DP、最优值+计数、树形 DP、DAG DP、分组/划分 DP |
| **第三层：偶尔出现的高级模型** | 大厂难题、专项面试或竞赛入门 | 状压 DP、博弈 DP、树上背包、数位 DP、自动机 DP |
| **第四层：低频专项** | 常规面试很少现场推导 | 换根 DP、概率/期望 DP、轮廓/插头 DP、各类 DP 优化 |

这个层级不是按时间复杂度排序，而是按面试学习投入产出比排序。

第一层中，一维状态的判断和现场书写是最基础也最容易产生歧义的部分，单独参见
[《原生一维DP判断与写作》](./原生一维DP判断与写作.md)；各题错误复盘和背包压缩推导参见
[《一维DP核心总结》](./一维DP核心总结.md)。

### 4. 下标和状态坐标的统一对照

`dp`数组的下标不一定是原数组的下标，更准确的叫法是**状态坐标**。

| 模型 | 状态坐标含义 | 与原数据的对应 |
|---|---|---|
| 前缀 DP | `i`是前缀长度 | 前缀是`[0,i)`，当前字符/元素是`i-1` |
| 后缀 DP | `i`是后缀起点 | 后缀是`[i,n)`，`i`是真实下标 |
| 结尾型 DP | `i`是强制结尾位置 | 方案必须使用`nums[i]` |
| 区间 DP | `left/right`是子区间端点 | 通常是真实闭区间`[left,right]` |
| 棋盘 DP | `row/column`是网格坐标 | 对应`grid[row][column]` |
| 背包 DP | `i`是物品前缀，`capacity`是容量 | 容量是数值状态，不是输入下标 |
| 状态机 DP | `i`是时间/位置，`state`是业务状态 | 例如第i天结束时持股/不持股 |
| 树形 DP | 坐标是`TreeNode` | 状态表示以当前节点为根的子树 |
| DAG DP | 坐标是图节点 | 必须沿拓扑序保证依赖先计算 |
| 状压 DP | `mask`压缩一组二元历史 | 第k位表示第k个对象是否被选择 |
| 数位 DP | `pos`是数字位置 | 常搭配`tight/started`等限制状态 |

## 二、分论：第一层，面试必会模型

## 1. 固定前驱线性 DP

### 状态特征

```text
dp[i]只依赖dp[i-1]、dp[i-2]等固定数量的相邻状态。
```

典型题目：

- [Q70 爬楼梯](./Q70_ClimbingStairs.java)
- [Q198 打家劫舍](./Q198_HouseRobber.java)

Q70使用前缀长度：

```text
dp[i] = 到达第i阶的方法数
dp[i] = dp[i-1] + dp[i-2]
```

Q198可以使用后缀起点：

```text
dp[i] = 房屋[i,n)范围内能偷到的最大金额
dp[i] = max(nums[i] + dp[i+2], dp[i+1])
```

### 面试关键点

1. 最后一步有固定数量的来源，不需要枚举所有历史位置。
2. 时间复杂度通常是`O(N)`。
3. 只依赖若干个旧状态时，可以压缩为`O(1)`空间。
4. 压缩时必须先用旧值计算新值，再移动状态。

## 2. 前缀/切分 DP

### 状态特征

```text
dp[end] = 前缀[0,end)的答案
```

`end`是长度，不是真实下标；前缀最后一个元素下标是`end-1`。第0格用来表示空前缀。

典型题目：[Q139 单词拆分](./Q139_WordBreak.java)。

```text
dp[end] = s[0,end)能否被字典完整切分
```

固定最后边界`end`，枚举最后一段的起点`start`：

```java
boolean[] dp = new boolean[s.length() + 1];
dp[0] = true;

for (int end = 1; end <= s.length(); end++) {
    for (int start = 0; start < end; start++) {
        if (dp[start] && dictionary.contains(s.substring(start, end))) {
            dp[end] = true;
            break;
        }
    }
}
```

### 面试关键点

```text
已处理前缀[0,start) + 最后一段[start,end) = 当前前缀[0,end)
```

通用步骤是：

1. 固定当前前缀的右开边界`end`。
2. 枚举最后一段的分割点`start`。
3. 检查左侧前缀状态是否成立。
4. 检查当前片段`[start,end)`是否合法。

常见错误是忘记`dp[0]`的空前缀含义，导致第一个片段无法开始。

## 3. 一维位置结尾型 DP

### 状态特征

```text
dp[i] = 必须以位置i结尾的局部答案
```

`i`是真实元素下标，当前方案必须使用`nums[i]`或`s[i]`。典型题目：

- [Q300 最长递增子序列](./Q300_LongestIncreasingSubsequence.java)
- [Q673 最长递增子序列的个数](./Q673_NumberOfLongestIncreasingSubsequence.java)
- [Q152 乘积最大子数组](./Q152_MaximumProductSubarray.java)
- [Q32 最长有效括号](./Q32_LongestValidParentheses.java)

Q300：

```text
dp[i] = 必须以nums[i]结尾的LIS长度
dp[i] = 1 + max(dp[j])，其中j<i且nums[j]<nums[i]
```

Q152需要同时保留两个数值极值属性：

```text
maxDp[i] = 必须以i结尾的最大乘积
minDp[i] = 必须以i结尾的最小乘积
```

负数会使最大值和最小值互换角色，因此两个属性都不能丢失。

### 答案位置

“必须以i结尾”只是局部状态，全局最优方案可能在任意位置结束，所以通常是：

```java
answer = Math.max(answer, dp[i]);
```

而不是直接返回`dp[n-1]`。详细对比见
[《一维位置结尾型DP.md》](./一维位置结尾型DP.md)。

## 4. 棋盘位置 DP

### 状态特征

```text
dp[row][column] = 到达真实网格坐标(row,column)时的答案
```

典型题目：

- [Q62 不同路径](./multidimensional/Q62_UniquePaths.java)
- [Q64 最小路径和](./multidimensional/Q64_MinimumPathSum.java)

Q62的状态值是方案数：

```text
dp[row][column] = dp[row-1][column] + dp[row][column-1]
```

Q64的状态值是最小代价：

```text
dp[row][column]
    = min(dp[row-1][column], dp[row][column-1])
    + grid[row][column]
```

两道题的状态拓扑相同，只是聚合算子不同。

### 面试关键点

1. `row/column`是真实坐标，数组通常就是`new int[m][n]`。
2. 不要机械地认为“DP必须多开一行一列”。
3. 边界格子可以单独初始化，也可以用哨兵值统一转移，但必须保证哨兵语义正确。

## 5. 双序列前缀 DP

### 状态特征

```text
dp[i][j] = 处理序列A的长度i前缀和序列B的长度j前缀时的答案
```

前缀分别是`A[0,i)`和`B[0,j)`，当前比较元素是`A[i-1]`和`B[j-1]`。

典型题目：

- [Q1143 最长公共子序列](./multidimensional/Q1143_LongestCommonSubsequence.java)
- [Q72 编辑距离](./multidimensional/Q72_EditDistance.java)
- [Q115 不同的子序列](./multidimensional/Q115_DistinctSubsequences.java)

Q1143：

```text
A[i-1] == B[j-1]：dp[i][j] = dp[i-1][j-1] + 1
A[i-1] != B[j-1]：dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

Q72在末尾字符不同时枚举最后一步：

```text
替换：dp[i-1][j-1] + 1
删除：dp[i-1][j] + 1
插入：dp[i][j-1] + 1
```

### 面试关键点

1. 第0行、第0列表示空前缀，所以数组是`[m+1][n+1]`。
2. `i/j`是长度，访问字符时必须使用`i-1/j-1`。
3. 转移必须根据当前子问题的末尾字符分类，不能根据完整输入的总长度关系决定局部操作。
4. 更详细的下标和遍历方向见
   [《多维DP核心总结.md》](./multidimensional/多维DP核心总结.md)。

## 6. 基础背包 DP

背包模型的原始逻辑状态通常是：

```text
dp[i][capacity] = 只使用前i种物品，容量为capacity时的答案
```

`i`通常是物品前缀长度，`capacity`是容量数值，不是原数组下标。

### 6.1 0-1 背包

每个物品最多使用一次。典型题目：
 [Q416 分割等和子集](./Q416_PartitionEqualSubsetSum.java)。

未压缩转移：

```text
dp[i][capacity] =
    不使用第i个元素的答案
    与
    使用第i个元素后剩余容量的答案
之间执行对应聚合
```

压缩成一维后，容量必须倒序：

```java
for (int num : nums) {
    for (int capacity = target; capacity >= num; capacity--) {
        dp[capacity] = dp[capacity] || dp[capacity - num];
    }
}
```

倒序的本质是：本轮计算只读取上一轮的旧状态，防止同一元素被重复使用。

### 6.2 完全背包

每种物品可以无限次使用。典型题目：

- [Q279 完全平方数](./Q279_PerfectSquares.java)
- [Q322 零钱兑换](./Q322_CoinChange.java)

完整二维转移可以枚举当前物品使用次数`k`：

```text
dp[i][capacity]
    = min/max over k (
        dp[i-1][capacity-k*weight[i]] + k*value[i]
      )
```

利用同一行已经计算的状态可以消除`k`枚举：

```text
dp[i][capacity]
    = best(
        dp[i-1][capacity],
        dp[i][capacity-weight] + value
      )
```

压缩后容量正序：

```java
for (int item = 0; item < weights.length; item++) {
    for (int capacity = weights[item]; capacity <= bag; capacity++) {
        dp[capacity] = Math.max(
                dp[capacity],
                dp[capacity - weights[item]] + values[item]
        );
    }
}
```

正序的本质是：允许当前状态读取本轮刚更新的状态，因而重复使用当前物品。

### 6.3 最小记忆结论

```text
0-1背包：每个元素最多一次，一维容量倒序。
完全背包：每个元素可以重复，一维容量正序。
```

但面试中不建议一开始就背一维版。稳定顺序是：暴力递归 -> 完整二维 DP -> 分析依赖 -> 空间压缩。

## 7. 单序列区间 DP

### 状态特征

```text
dp[left][right] = 闭区间[left,right]上的答案
```

典型题目：

- [Q5 最长回文子串](./multidimensional/Q5_LongestPalindromicSubstring.java)
- [Q516 最长回文子序列](../../dp/PalindromeSubsequence.java)

Q5可以定义：

```text
dp[left][right] = s[left..right]是否为回文串
```

转移：

```java
dp[left][right] = chars[left] == chars[right]
        && (right - left <= 2 || dp[left + 1][right - 1]);
```

当前区间依赖更短的内部区间，因此可以：

```text
left从大到小，right从left到大；
或者按区间长度从小到大填表。
```

### 面试关键点

1. 先画出一个小的二维表，确认哪一半是合法区域。
2. 明确依赖是内部区间、左缩区间还是右缩区间。
3. 按区间长度递增通常最不容易写错，适合面试现场。

## 8. 线性状态机 DP

### 状态特征

```text
dp[i][state] = 处理到位置i，并且结束时处于state状态的最优答案
```

状态必须“足够概括历史”：得知当前状态和对应最优值后，未来决策不再需要知道完整过去。

典型题目：[股票系列](./stock/股票问题总结.md)。

基础股票问题：

```text
cash[i] = 第i天结束时不持股的最大收益
hold[i] = 第i天结束时持股的最大收益
```

```text
cash[i] = max(cash[i-1], hold[i-1] + price[i])
hold[i] = max(hold[i-1], cash[i-1] - price[i])
```

### 为什么有时需要增加状态

如果两种历史对未来操作权限不同，就不能合并。例如冷冻期：

```text
普通不持股：明天可以买入
今天刚卖出：明天不能买入
```

两者对未来的合法转移不同，因此必须拆成`sold/rest`。

### 存储压缩

状态数量很少时，可以按以下顺序压缩：

```text
dp[n][stateCount]
    -> 每个state一个一维数组
    -> 每个state一个常数变量
```

压缩为变量时，如果多个新状态都依赖上一轮的旧状态，必须先保存旧值快照。

## 三、分论：第二层，中高频进阶模型

## 9. 计数 DP：这是状态值语义，不是新坐标

计数 DP 可以与前缀、棋盘、背包、树形等任何状态拓扑组合。

### 9.1 纯计数 DP

所有合法来源都是答案，直接求和。

例如 [Q115 不同的子序列](./multidimensional/Q115_DistinctSubsequences.java)：

```text
dp[i][j] = s前i个字符组成t前j个字符的方案数
```

当`s[i-1] == t[j-1]`时：

```text
dp[i][j] = dp[i-1][j] + dp[i-1][j-1]
           不使用s[i-1]   使用s[i-1]
```

### 9.2 最优值 + 最优方案数

先判断候选方案是否达到最优，只统计最优方案。

例如 [Q673 LIS的个数](./Q673_NumberOfLongestIncreasingSubsequence.java)：

```java
if (candidateLength > length[i]) {
    length[i] = candidateLength;
    count[i] = count[j];       // 发现更优长度：覆盖旧计数
} else if (candidateLength == length[i]) {
    count[i] += count[j];      // 同样优：累加新来源
}
```

`length[i]`和`count[i]`是同一个状态坐标`i`上的两个属性，不是多出一个独立状态参数。

## 10. 树形 DP

### 状态特征

```text
Info process(node) = 以node为根的整棵子树向父节点汇报的完整信息
```

数组 DP 在下标空间上递推，树形 DP 在树的结构上递推。通常使用后序遍历：

```java
Info left = process(node.left);
Info right = process(node.right);
Info current = merge(node, left, right);
return current;
```

关键不是会写`Info`类，而是在写递归之前严格定义：

```text
1. Info的每个字段是整棵子树的全局信息，还是必须经过当前节点的局部信息？
2. 空树对每个字段应该返回什么？
3. 父节点如何用左右子树信息合并当前Info？
```

常见题型：树的最大距离、最大路径和、是否平衡、最大 BST 子树、树上选或不选。

## 11. DAG DP

如果图是有向无环图，拓扑序就是天然的 DP 计算顺序。

```text
dp[node] = 到达node的最长路径/最短路径/方案数
```

例如计算从起点到每个节点的路径数：

```java
dp[start] = 1;
for (int from : topologicalOrder) {
    for (int to : graph.get(from)) {
        dp[to] += dp[from];
    }
}
```

基础区分：

```text
BFS/DFS主要解决可达性和遍历顺序；
DAG DP利用拓扑顺序聚合所有前驱状态。
```

如果图中存在环，普通拓扑 DP 就不能直接使用，需要根据题意缩点、增加维度或改用其他模型。

## 12. 分组/划分 DP

常见状态：

```text
dp[i][groups] = 将前i个元素划分成groups组时的最优答案
```

固定最后一组的右边界`i`，枚举最后一组的左边界`split`：

```text
dp[i][groups]
    = best over split (
        dp[split][groups-1]
        + cost(split, i)
      )
```

它可以理解为“前缀切分 DP + 组数限制维度”。难点通常在：

1. `cost(split,i)`是否能够预处理或`O(1)`计算。
2. 不可达状态的哨兵是否正确。
3. 枚举范围是否保证每组非空。

---

## 四、分论：第三层，偶尔出现的高级模型

## 13. 状态压缩 DP

当历史中需要记录一组对象是否已使用，并且对象数量较小时，可以用一个二进制整数压缩这组布尔状态。

```text
mask的第k位为1：第k个对象已使用
mask的第k位为0：第k个对象未使用
```

旅行商模型：

```text
dp[mask][last] = 已访问mask中的点，当前停在last时的最小代价
```

典型复杂度是`O(2^N * N^2)`，因此常规只适合`N`较小的场景。

## 14. 博弈 DP

博弈 DP 要先明确当前玩家和对手的目标。常用定义：

```text
dp[state] = 当前玩家从state开始，相对对手能获得的最大分差
```

当前玩家选择一步后，角色交换，因此常见转移是：

```text
dp[state] = max(当前得分 - dp[nextState])
```

难点不在填表，而在状态值必须统一从“当前行动者”视角解释，否则正负号很容易错乱。

## 15. 树上背包

树上背包将树形 DP 和背包 DP 组合：

```text
dp[node][k] = 在node的子树中选择k个对象时的最优答案
```

合并一个孩子时，需要枚举：

```text
当前子树总共选多少；
其中分配给这个孩子的子树多少。
```

它比普通树形 DP 多了容量维度，也比线性背包多了子树合并过程。

## 16. 数位 DP

数位 DP 用于统计数值区间中满足某种数字位约束的整数个数，常将区间问题转换为：

```text
count(0..R) - count(0..L-1)
```

常见状态：

```text
dfs(pos, previous, tight, started, otherState)
```

| 状态 | 含义 |
|---|---|
| `pos` | 当前处理到第几个数位 |
| `tight` | 前缀是否仍然紧贴上界，决定当前位上限 |
| `started` | 是否已经放入第一个非前导零数字 |
| `otherState` | 数位和、模数、前一位数字等题目特有限制 |

它的状态定义和边界细节较多，普通算法面试中优先级低于基础背包、树形 DP 和状压 DP。

## 17. 自动机 DP

当序列选择必须满足某种模式，并且过去可以被压缩成有限个匹配状态时，可以将自动机状态放入 DP：

```text
dp[position][automatonState] =
处理到position时，模式匹配处于automatonState的答案
```

其核心是自动机将“已经匹配了多少、下一个字符会跳到哪里”压缩为有限状态。实现往往与 KMP、Trie、Aho-Corasick 或专门构建的 DFA 结合。

---

## 五、分论：第四层，常规面试低频专项

## 18. 换根 DP

普通树形 DP 固定一个根，计算每个子树的信息；换根 DP 还需要得到“每个节点分别作为根”时的答案。

常用两次 DFS：

```text
第一遍：子 -> 父，统计子树信息。
第二遍：父 -> 子，把子树外部的信息传递给孩子。
```

最难的部分是在父子换根时，正确扣除孩子原贡献，再加入父方向的新贡献。

## 19. 概率 DP 与期望 DP

概率 DP 的状态值是概率：

```text
prob[state] = 从起点到达state的概率
```

期望 DP 的状态值是从当前状态到目标的期望代价：

```text
E[state] = cost(state) + sum(probability * E[nextState])
```

如果转移会回到当前状态，方程中可能同时出现`E[state]`的左右两边，需要代数移项，而不是简单按表格顺序填写。

## 20. 轮廓 DP / 插头 DP

这类模型常用于棋盘铺砖、网格连通性和 Hamilton 路径计数等问题。它只保留扫描线附近的局部连通状态，通常需要状压或括号序列编码。

其状态设计、去重和合法性判断都较重，普通工程岗面试几乎不需要优先投入。

## 21. DP 优化技术不是新 DP 模型

以下名称主要描述“如何加速转移”，不是独立的状态拓扑：

| 优化方式 | 消除的瓶颈 |
|---|---|
| 滚动数组/变量压缩 | 重复保存不再需要的历史层 |
| 前缀和 | 重复计算一段转移和或区间代价 |
| 单调队列 | 重复求滑动窗口内最值 |
| Fenwick/线段树 | 动态前缀聚合或值域范围查询 |
| 分治优化 | 决策点具有单调性时减少枚举 |
| 斜率优化 | 转移可化为直线极值查询 |
| Knuth 优化 | 特定区间 DP 的最优分割点具有单调性 |

面试中应先写出正确的基础 DP，再根据数据范围判断是否必须优化。

---

## 六、补充：“后缀 DP”为什么没有被单独列成主模型

后缀 DP 当然存在，但它通常是计算方向，而不是与前缀 DP 本质不同的状态拓扑。

```text
前缀定义：dp[i] = 范围[0,i)的答案
后缀定义：dp[i] = 范围[i,n)的答案
```

两者通常可以通过反转输入、改变递归方向或重新定义状态相互转化。

例如 Q198 打家劫舍可以同时写成：

```text
前缀：dp[i] = 考虑前i个房屋的最大收益
后缀：dp[i] = 考虑房屋[i,n)的最大收益
```

选哪个方向的标准是：转移是否自然、边界是否清晰、是否便于与题意对应。普通离线问题中，很少存在“只能用后缀 DP 才能解决”的情况。

## 七、总结：面试现场的统一判断流程

## 1. 先判断状态拓扑

```text
只需要位置i，且依赖固定前驱？
    -> 固定前驱线性 DP

答案针对前缀[0,i)，需要枚举最后分割点？
    -> 前缀/切分 DP

方案必须以位置i结尾？
    -> 位置结尾型 DP

问题在真实网格坐标上移动？
    -> 棋盘 DP

同时处理两个序列前缀？
    -> 双序列前缀 DP

状态包含“只使用前i个对象 + 容量/目标值”？
    -> 背包 DP

子问题由[left,right]确定？
    -> 区间 DP

未来决策依赖当前的持有/冷冻/交易次数等业务状态？
    -> 状态机 DP

输入是树，父节点需要汇总子树信息？
    -> 树形 DP

输入是DAG，当前节点需要汇总所有前驱？
    -> DAG DP

需要记录一组小规模对象的选择集合？
    -> 状压 DP
```

## 2. 再判断状态值语义

| 题目问法 | 状态值 | 来源聚合 |
|---|---|---|
| 能不能做到 | `boolean` | 逻辑或 |
| 最多/最大 | 最大值 | `max` |
| 最少/最小 | 最小值 | `min` |
| 有多少种方案 | 方案数 | 对所有合法来源求和 |
| 最优方案有多少种 | 最优值 + 计数 | 更优时覆盖，同样优时累加 |
| 输出具体方案 | 最优值 + 决策/前驱 | 在DP后回溯或同步记录选择 |

## 3. 然后完整写出六件事

1. **状态定义**：每个维度和`dp`值分别表示什么。
2. **选择集合**：当前状态可以做哪些决策。
3. **转移方程**：每个选择依赖哪个更小状态。
4. **Base case**：空前缀、容量0、叶节点、单点区间等状态的答案。
5. **遍历方向**：保证当前状态依赖的格子已经完成。
6. **答案位置**：是`dp[n]`、`dp[0]`、`dp[m][n]`、`dp[0][n-1]`，还是需要扫描所有局部状态。

## 4. 最后才做存储和时间优化

```text
逻辑状态是什么？
    -> 先保持完整表格

当前层只依赖上一层？
    -> 考虑滚动数组

只依赖固定数量的历史状态？
    -> 考虑常数变量

背包压缩成一维？
    -> 根据当前元素能否重复使用决定倒序/正序

已经正确，但复杂度超过数据范围？
    -> 再查找决策单调性、区间聚合或专用优化
```

## 5. 最终学习顺序

```text
第一阶段：
固定前驱 -> 前缀切分 -> 结尾型 -> 棋盘 -> 双序列

第二阶段：
0-1背包 -> 完全背包 -> 区间 -> 股票状态机 -> 计数DP

第三阶段：
树形DP -> DAG DP -> 分组DP -> 状压DP

有明确专项需求再学：
博弈 -> 树上背包 -> 数位 -> 自动机 -> 换根 -> 轮廓 -> DP优化
```

面试中最稳定的表达不是“我记得这道题的模板”，而是：

```text
我先定义子问题和状态坐标；
再枚举当前状态的最后一步/选择；
根据依赖关系确定初始值、遍历方向和答案位置；
正确性成立之后，再考虑空间压缩和时间优化。
```

这套顺序能够把“背转移方程”变成“现场重新推导转移方程”。
