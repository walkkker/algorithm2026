## 一句话总纲

```text
先定义递归函数或Info对“一棵以cur为根的子树”返回什么，
再决定信息是由子树向父节点汇总，还是由祖先向当前节点传递。
```

二叉树题的核心不是“会递归”，而是维护递归接口契约：

- 返回值属于当前节点还是整棵当前子树？
- 是否必须包含当前节点？
- 能否继续交给父节点连接？
- 左右孩子能选择一侧还是两侧？
- 空树返回什么？
- 统计的是节点数、边数、层数还是节点值之和？

## 题型地图

| 模型 | 信息方向 | Hot 100题目 | 项目扩展 |
| --- | --- | --- | --- |
| DFS遍历 | 递归栈模拟访问顺序 | Q94 | 前序、后序、Morris |
| BFS分层 | 队列按层消费 | Q102、Q199 | 最大宽度、序列化 |
| 直接递归改写 | 子树处理完后返回新子树根 | Q226、Q108 | N叉树编码 |
| 双节点递归 | 同时比较两棵对应子树 | Q101 | 树结构相等、镜像判断 |
| 底向上Info汇总 | 左右子树 -> 当前节点 | Q104、Q543、Q124、Q236 | 平衡树、满树、最大BST子树 |
| 自顶向下路径状态 | 祖先上下文 -> 当前节点 | Q437 | 根到叶路径、路径字符串 |
| BST有序性 | 中序有序或上下界约束 | Q98、Q230 | SBT维护size、后继节点 |
| 数组区间建树 | 根位置切分左右区间 | Q105、Q108 | 序列化重建 |
| 原地结构改写 | 保存原指针，再按目标顺序重连 | Q114、Q226 | Morris线索化 |

## 面试优先级

### P0：基础骨架必须熟练

| 题目 | 必须掌握的模型 |
| --- | --- |
| Q94 中序遍历 | 递归顺序；显式栈循环条件`cur != null || !stack.isEmpty()` |
| Q104 最大深度 | `height = max(left,right) + 1`，空树高度为0 |
| Q226 翻转二叉树 | 覆盖孩子指针前保存原左右子树 |
| Q101 对称二叉树 | 双节点镜像递归：外侧对外侧、内侧对内侧 |
| Q102 层序遍历 | 队列按层读取`levelSize`，空树先返回 |

### P1：常见递归模型

| 题目 | 核心能力 |
| --- | --- |
| Q98 验证BST | 严格中序递增，或为每个节点传递合法上下界 |
| Q108 有序数组转BST | 中点作为根，递归构造左右区间 |
| Q105 前序+中序建树 | 根值定位、左子树长度、四个区间边界 |
| Q543 二叉树直径 | 向上返回高度，同时维护子树完整答案；统一边/节点单位 |
| Q236 最近公共祖先 | 子树已有答案优先传播；否则在当前节点第一次汇合 |
| Q199 右视图 | 层序遍历每层最后节点，或DFS优先右子树并按深度首次收集 |
| Q230 BST第K小 | 中序第K个；频繁查询时节点维护子树size |

### P2：高风险综合题

| 题目 | 难点 |
| --- | --- |
| Q114 展开为链表 | 递归返回尾节点与原地前驱法；改指针时不能丢失右子树 |
| Q437 路径总和III | 根路径前缀和、HashMap计数、进入加一与离开回溯 |
| Q124 最大路径和 | “可向父节点延伸的单链”与“子树完整答案”必须分离 |

## 推荐复习顺序

```text
Q94
  -> Q104
  -> Q226
  -> Q101
  -> Q102 / Q199
  -> Q98 / Q230
  -> Q108 / Q105
  -> Q543
  -> Q236
  -> Q114
  -> Q437
  -> Q124
```

顺序依据：先掌握访问顺序，再掌握单返回值递归，然后进入多状态Info、祖先上下文和原地结构改写。

## 三种递归必须区分

### 1. 直接递归

```java
TreeNode process(TreeNode cur)
```

返回处理后的当前子树根。典型题：Q226、Q108、Q105。

### 2. 底向上Info

```java
Info left = process(cur.left);
Info right = process(cur.right);
return combine(left, right, cur);
```

父节点答案完全由左右子树固定信息和当前节点得到。典型题：Q543、Q124、Q236。

### 3. 自顶向下携带上下文

```java
dfs(cur, stateFromAncestors)
```

当前节点依赖根到当前路径、祖先集合或剩余目标。典型题：Q437。此类题不能强行塞入固定Info。

## 写递归前的状态契约

建议先写：

```text
函数处理范围：以cur为根的整棵子树
返回值含义：
是否必须包含cur：
是否可以交给父节点继续组合：
允许连接几个孩子：
统计单位：
cur == null时返回：
最终答案从哪里读取：
```

如果这些问题无法明确回答，代码即使能编译，也很可能发生语义错用。

## 最终记忆

```text
遍历题先确定访问时机。
递归题先定义返回值，不要先写左右递归。
完整答案和可向父节点延伸的信息通常不是同一个状态。
依赖祖先路径时使用自顶向下状态，不要强行Info。
修改left/right前先保存仍需访问的原指针。
节点数、边数、层数必须从base case开始统一。
```
