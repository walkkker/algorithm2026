# 非标准Info递归题目清单

## 先明确分类标准

左神“二叉树递归套路”本质上是后序位置的树形DP：

```java
Info left = process(cur.left);
Info right = process(cur.right);
return combine(left, right, cur);
```

它成立的前提是：**当前子树需要向父节点提供的信息，可以由左子树固定Info、右子树固定Info和
当前节点合并得到。**

以下题目不是“不能使用Java递归”，而是**不应该优先强套单节点后序Info模型**。它们依赖的是
遍历顺序、层边界、双节点关系、祖先路径状态、数组区间、BST有序性或原地指针改写。

## 一、Hot 100中应先单独学习的题目

### P0：基础独立骨架

| 题目 | 独立技巧 | 为什么不是标准Info汇总 |
| --- | --- | --- |
| Q94 二叉树中序遍历 | 递归访问时机、显式栈 | 目标是按左-根-右顺序访问，不是计算子树摘要 |
| Q102 层序遍历 | BFS队列、冻结每层大小或维护层尾 | 信息按层传播，后序Info不能自然表达层次顺序 |
| Q101 对称二叉树 | 双节点镜像递归 | 递归状态是一对节点，配对为外侧对外侧、内侧对内侧 |
| Q226 翻转二叉树 | 直接递归改写、覆盖前冻结原指针 | 目标是修改结构并返回新子树根，不需要汇总Info |

Q226必须特别记住：连续两条字段赋值按顺序执行，不是同时交换。第一条语句覆盖`cur.left`后，
第二条语句再读取`cur.left`得到的是新值。只要后续还需要原左右子树，就必须提前保存
`oldLeft/oldRight`，再执行递归赋值。

### P1：有序性与区间构造

| 题目 | 独立技巧 | 核心状态 |
| --- | --- | --- |
| Q199 二叉树右视图 | BFS每层最后节点；或右优先DFS按深度首次收集 | 层号/深度来自祖先方向，而不是子树Info |
| Q230 BST第K小 | BST中序严格递增、显式栈提前停止 | 依赖中序访问次序；动态版本维护子树size |
| Q108 有序数组转BST | 数组区间递归、中点建根 | 状态是`[l,r]`区间，递归负责创建结构 |
| Q105 前序和中序建树 | 根位置、左子树长度、双数组区间同步切分 | 状态是两组数组边界，不是已有左右子树Info |

### P2：祖先状态与原地结构技巧

| 题目 | 独立技巧 | 最关键的不变量 |
| --- | --- | --- |
| Q437 路径总和III | 根路径前缀和、HashMap频次、回溯恢复 | Map只表示当前根到cur路径上的前缀和 |
| Q114 展开为链表 | 递归返回尾节点；最优版本为原地前驱重连 | 前序待处理顺序必须保存在树自身的right指针中 |

Q437尤其重要：它虽然使用递归，但信息方向是：

```text
祖先路径状态 -> 当前节点 -> 子节点
```

标准Info的信息方向则是：

```text
左右子树 -> 当前节点 -> 父节点
```

两者方向相反。Q437强行使用固定Info通常会丢失路径上下文，或者退化为枚举每个起点的
`O(N^2)`解法。

## 二、边界题：既能Info，也有更直接模型

### Q98 验证二叉搜索树

它可以使用标准Info：每棵子树返回`isBST/min/max`；但面试中更直接的是：

```text
BST中序遍历必须严格递增。
```

也可以自顶向下传递开放上下界`(lower, upper)`。因此Q98不是“Info做不了”，而是必须掌握
BST有序性这一独立性质。

### Q114 二叉树展开为链表

递归版本可以视为简化Info：左右子树分别返回展开后的尾节点，再由当前节点拼接；但题目的
`O(1)`额外空间版本依赖原地结构改写，必须单独学习：

```text
找到左子树最右节点
-> 接住原右子树
-> 左子树整体搬到right
-> left置null
```

这套写法不使用递归栈、显式Stack或Queue，只使用固定数量的TreeNode引用，因此辅助空间为
`O(1)`。它利用原树的right指针保存“前序遍历中稍后还要处理的原右子树”。

可以从两个尺度理解：

```text
微观：每个cur都把自己的左子树插入cur与原右子树之间。
宏观：不断cur = cur.right，最终所有left为空，right链顺序就是前序遍历。
```

左子树最右节点只是当前结构的右边界，不一定已经是完整左子树最终前序链的尾节点。后续处理会
继续调整其内部结构，因此不要把它机械理解成已经确定的“前序最后节点”。

## 最终判断口诀

```text
要访问顺序：遍历/栈。
要逐层信息：BFS。
要比较两棵关系：双节点递归。
要依赖祖先路径：自顶向下参数 + 回溯。
要利用BST大小关系：中序或上下界。
要从数组造树：区间递归。
要修改树结构：先保存原指针，再重连。
只有“左右子树摘要可以合并成当前子树摘要”，才优先使用Info套路。
```
