# 子串与子序列区别

## 一、最重要案例：回文子串与回文子序列

> **这是区分“子串 DP”和“子序列 DP”的第一优先级案例。**
>
> 两道题都可以定义区间状态 `dp[left][right]`，但相同的二维数组外形不代表相同的状态语义。
> 子串必须使用区间内的全部字符；子序列允许跳过字符。这个区别直接决定状态值类型和转移方程。

### 1. 先记住根本区别

```text
回文子串：必须连续，区间[left,right]内的每个字符都必须使用。
回文子序列：只要求保持相对顺序，区间内的字符可以主动跳过。
```

因此，面对区间两端字符不相等时，两道题的处理完全不同：

```text
回文子串：当前完整区间直接失败。
回文子序列：可以丢弃左端或右端，继续在更小区间中寻找答案。
```

### 2. Q5 最长回文子串

#### 2.1 状态定义

```text
dp[left][right]表示连续区间s[left...right]整体是否为回文串。
```

状态值是 `boolean`，因为固定区间只需要回答：

```text
这个完整连续区间是不是回文串？
```

这里的“整体”不能省略。`dp[left][right]`不是区间内最长回文子串的长度，也不是区间内是否存在
某个回文子串。

#### 2.2 状态转移

一个长度至少为 3 的连续区间成为回文串，必须同时满足：

```text
1. s[left] == s[right]
2. 内部连续区间s[left+1...right-1]整体也是回文串
```

因此：

```java
dp[left][right] = chars[left] == chars[right]
        && dp[left + 1][right - 1];
```

长度为 1 或 2 时，内部区间为空，不应该访问非法下标，可以统一写为：

```java
dp[left][right] = chars[left] == chars[right]
        && (right - left <= 1 || dp[left + 1][right - 1]);
```

#### 2.3 遍历顺序

`dp[left][right]`依赖：

```text
dp[left+1][right-1]
```

所以必须保证更靠下、更靠内的区间先计算：

```text
left：从大到小
right：从left到N-1
```

也可以按照区间长度从小到大枚举。两种顺序本质相同，都是先计算短区间，再计算长区间。

#### 2.4 标准代码

```java
public String longestPalindrome(String s) {
    char[] chars = s.toCharArray();
    int n = chars.length;
    boolean[][] dp = new boolean[n][n];

    int bestStart = 0;
    int bestLength = 1;

    for (int left = n - 1; left >= 0; left--) {
        for (int right = left; right < n; right++) {
            if (chars[left] == chars[right]
                    && (right - left <= 1 || dp[left + 1][right - 1])) {
                dp[left][right] = true;

                int length = right - left + 1;
                if (length > bestLength) {
                    bestLength = length;
                    bestStart = left;
                }
            }
        }
    }

    return s.substring(bestStart, bestStart + bestLength);
}
```

最终答案不能直接读取 `dp[0][n-1]`，因为整个字符串不一定是回文串。需要在所有值为 `true` 的区间中
记录最长区间。

#### 2.5 最致命的错误

不能写成：

```java
dp[left][right] = Math.max(
        dp[left + 1][right],
        dp[left][right - 1]
);
```

这两个来源分别丢弃了左端字符或右端字符。一旦允许丢弃字符，得到的就不再是原字符串中的连续子串，
而是子序列模型。

Q5 的 DP 时间复杂度为 `O(N^2)`，空间复杂度为 `O(N^2)`。本题还可以使用中心扩展在
`O(N^2)` 时间、`O(1)` 额外空间内完成；Manacher 算法可以达到 `O(N)` 时间。

### 3. Q516 最长回文子序列

#### 3.1 状态定义

```text
dp[left][right]表示区间s[left...right]中最长回文子序列的长度。
```

这里的状态值是 `int`，状态询问的不是“整个区间是不是回文”，而是：

```text
允许从这个区间中选择部分字符时，能够组成的最长回文序列有多长？
```

#### 3.2 状态转移

当首尾字符相等时，可以同时选择它们：

```java
dp[left][right] = dp[left + 1][right - 1] + 2;
```

当首尾字符不相等时，它们不能同时作为当前回文子序列的首尾，至少需要丢弃一个：

```java
dp[left][right] = Math.max(
        dp[left + 1][right],
        dp[left][right - 1]
);
```

这正是子序列“不要求连续”的代码体现：

```text
dp[left+1][right]：不选择s[left]
dp[left][right-1]：不选择s[right]
```

#### 3.3 Base case 与遍历顺序

单个字符自身构成长度为 1 的回文子序列：

```java
dp[i][i] = 1;
```

它同样依赖更小的内部区间，因此可以让 `left` 从大到小、`right` 从 `left+1` 到 `N-1`。

#### 3.4 标准代码

```java
public int longestPalindromeSubseq(String s) {
    char[] chars = s.toCharArray();
    int n = chars.length;
    int[][] dp = new int[n][n];

    for (int i = 0; i < n; i++) {
        dp[i][i] = 1;
    }

    for (int left = n - 2; left >= 0; left--) {
        for (int right = left + 1; right < n; right++) {
            if (chars[left] == chars[right]) {
                dp[left][right] = dp[left + 1][right - 1] + 2;
            } else {
                dp[left][right] = Math.max(
                        dp[left + 1][right],
                        dp[left][right - 1]
                );
            }
        }
    }

    return dp[0][n - 1];
}
```

这里可以直接返回 `dp[0][n-1]`，因为它的状态定义就是整个字符串范围内能够选择出的最长回文
子序列，不要求整个字符串本身是回文。

### 4. 使用同一个样例对照

```text
s = "agbdba"
```

最长回文子串是：

```text
"bdb"，长度为3
```

最长回文子序列是：

```text
"abdba"，长度为5
```

`"abdba"`需要跳过原字符串中的字符 `g`，所以它是子序列，但不是子串。

再看：

```text
s = "bbbab"
```

```text
最长回文子串："bbb"，长度为3
最长回文子序列："bbbb"，长度为4，需要跳过字符'a'
```

### 5. 核心横向对比

| 对比项 | 回文子串 | 回文子序列 |
|---|---|---|
| 是否连续 | 必须连续 | 不要求连续，但保持相对顺序 |
| 状态定义 | `[left,right]`整体是否为回文串 | `[left,right]`内最长回文子序列长度 |
| 状态值类型 | `boolean` | `int` |
| 首尾相等 | 还必须检查内部整体是否回文 | 首尾都选，内部答案加 2 |
| 首尾不等 | 当前区间直接失败 | 丢弃左端或右端，取最大值 |
| 是否允许跳过字符 | 不允许 | 允许 |
| 最终答案 | 扫描全部合法区间，记录最长者 | `dp[0][n-1]` |
| DP时间复杂度 | `O(N^2)` | `O(N^2)` |
| 常见替代算法 | 中心扩展、Manacher | 典型解法仍是区间 DP |

### 6. 从回文案例推广到所有子串与子序列 DP

#### 6.1 子串和子数组 DP

子串、子数组要求连续，因此常见状态是：

```text
dp[left][right]：完整连续区间[left,right]是否满足条件。
dp[i]：必须以位置i结尾的最长或最优连续答案。
```

“必须以 `i` 结尾”能够维持连续性，因为新元素只能连接位置 `i-1` 所在的连续结果。典型题包括：

```text
Q5：连续区间是否为回文串
Q32：必须以i结尾的最长有效括号
Q53：必须以i结尾的最大子数组和
Q152：必须以i结尾的最大、最小乘积
```

#### 6.2 子序列 DP

子序列允许跳过字符，因此转移中经常出现：

```text
选择当前位置 / 不选择当前位置
丢弃左端 / 丢弃右端
使用当前字符匹配 / 跳过当前字符
```

典型题包括：

```text
Q300：必须以nums[i]结尾的最长递增子序列
Q516：丢弃左端或右端的区间DP
Q1143：两个前缀的最长公共子序列
Q115：使用或跳过源字符串当前字符的计数DP
```

### 7. 面试判断口诀

```text
先问是否必须连续。

必须连续：区间内字符不能跳过；首尾不满足条件，完整区间通常直接失败。
允许不连续：可以出现“不选、跳过、丢左、丢右”的转移。
```

看到下面的转移时：

```java
Math.max(dp[left + 1][right], dp[left][right - 1])
```

应该立刻意识到它允许丢弃字符，因此表达的是子序列逻辑，而不是子串逻辑。

最终必须能够不看代码说出：

```text
回文子串判断完整连续区间，所以首尾不等时区间失败；
回文子序列允许跳过字符，所以首尾不等时可以丢左或丢右。
```

## 二、先区分三个概念

| 概念 | 是否连续 | 是否保持相对顺序 | 长度为N时的候选规模 |
|---|---|---|---|
| 子串 substring | 必须连续 | 自动保持 | `N(N+1)/2`个位置区间 |
| 子数组 subarray | 必须连续 | 自动保持 | `N(N+1)/2`个位置区间 |
| 子序列 subsequence | 不要求连续 | 必须保持 | 最多`2^N`种下标选择 |

子串和子数组的区别仅在输入载体：字符串中的连续段叫子串，数组中的连续段叫子数组。子序列允许跳过
中间元素，因此每个位置都可能出现“选或不选”的组合决策。

## 三、为什么子串较少使用DP

子串一旦确定左右边界`[left,right]`，中间内容随之唯一确定；连续性通常还能形成可增量维护的窗口，
所以优先考虑：

1. 滑动窗口：窗口条件在扩张/收缩时可以增量维护。
2. 前缀和/前缀计数：区间值可以由两个前缀状态相减。
3. 中心扩展、Manacher：利用回文的中心对称。
4. KMP、Z Algorithm、滚动哈希：处理模式匹配。
5. 结尾型DP：当前连续答案只能连接`i-1`时使用。

子串不是不能使用DP。Q5可以定义`dp[left][right]`表示区间是否回文；Q32可以定义`dp[i]`
表示必须以i结尾的最长有效括号长度。但如果存在更直接的窗口、中心或字符串专用算法，应当比较复杂度。

## 四、为什么子序列经常使用DP

子序列不要求连续。求最优值或方案数量时，每个位置通常有“选择、跳过”两种行为，暴力枚举规模可达
`2^N`。DP通过保存前缀、结尾位置或左右区间的答案，合并重复子问题。

但“子序列一定使用DP”是错误结论：如果只判断一个固定序列能否按顺序匹配，双指针即可；LIS还可以
利用单调性使用贪心+二分优化。

## 五、Q115与Q673的计数区别

### Q115：纯计数DP

```text
dp[i][j] = s前i个字符组成t前j个字符的全部方案数
```

不存在最优值比较，所有合法来源直接相加：

```text
字符不同：dp[i][j] = dp[i-1][j]
字符相同：dp[i][j] = dp[i-1][j] + dp[i-1][j-1]
```

### Q673：最优值+最优方案计数

```text
length[i] = 必须以nums[i]结尾的最优长度
count[i]  = 达到length[i]的方案数量
```

```text
发现更长候选：覆盖length[i]，同时用count[j]覆盖count[i]
发现同长候选：保留length[i]，把count[j]累加到count[i]
发现更短候选：忽略
```

`count[i]`是状态i的第二个属性，不是新的独立状态参数。状态仍然只由结尾位置i确定。

## 七、面试判断流程

```text
1. 是否要求连续？
   是：优先窗口、前缀、中心扩展、单调结构；再考虑连续结尾型DP。
   否：进入子序列模型。

2. 子序列是否只做一次顺序匹配？
   是：双指针。
   否：继续分析前缀、结尾位置或区间状态。

3. DP格子保存什么？
   能否完成：boolean可行性。
   最大/最小：最优值DP。
   所有合法方案：纯计数DP。
   最优方案数量：最优值+计数。

4. 最终答案在哪里？
   前缀型通常在dp[n]或dp[m][n]；
   必须以i结尾型通常需要扫描全部i；
   区间型整段答案通常在dp[0][n-1]。
```

## 八、核心结论

> 连续性减少了边界选择自由度，因此子串和子数组经常存在窗口、前缀或中心类算法；子序列允许跳跃
> 选择，优化和计数问题更容易形成DP。但算法选择最终取决于问题目标，不应只根据“子串/子序列”名称
> 机械套模板。
