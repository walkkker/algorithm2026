# 字典序排列家族

## 一、总论：这三道题确实属于同一个排列家族

“字典序排列家族”不是 LeetCode 的官方分类名称，但是一个准确且很有价值的知识组织方式。

对于互不相同的`N`个元素，它们共有`N!`个排列。如果将这些排列按字典序放在一条有序序列上，
三道题对应的就是三种不同的访问方式：

```text
Q46 全排列：枚举整个排列空间
Q31 下一个排列：当前排列 -> 字典序直接后继
Q60 排列序列：字典序排名k -> 对应排列
```

用更专业的术语表达：

```text
Q31：successor，求有序排列空间中的直接后继
Q60：unranking，将排名反解成排列
扩展：ranking，将排列计算为字典序排名
```

核心关系可以概括为：

```text
字典序最小排列
    --反复执行Q31-->
按字典序枚举出全部Q46结果

字典序最小排列
    --执行k-1次Q31-->
第k个排列

排名k
    --阶乘分块直接定位-->
Q60的第k个排列
```

最后一种方法不需要经过前面`k-1`个中间排列，这就是 Q60 的核心价值。

## 二、使用同一个例子建立全局视角

对于`[1,2,3]`，全部排列的字典序为：

| 1-based排名 | 0-based排名 | 排列 |
|---:|---:|---|
| 1 | 0 | `123` |
| 2 | 1 | `132` |
| 3 | 2 | `213` |
| 4 | 3 | `231` |
| 5 | 4 | `312` |
| 6 | 5 | `321` |

从这张表出发：

```text
Q46：返回这6个排列。
Q31：输入213，返回231；输入321，回到123。
Q60：输入n=3、k=4，直接返回231。
```

因此，学习顺序建议是：

```text
先理解Q46的排列空间
    -> 再理解Q31如何从一个排列走到紧邻的下一个
    -> 最后理解Q60如何用数学分块跳到任意排名
```

## 三、Q46：枚举整个排列空间

## 1. 回溯生成器

项目原有实现：
[《Q46_Permutations.java》](../Backtracking/Q46_Permutations.java)。

交换回溯的递归不变量是：

```text
nums[0,index)           已经确定的排列前缀
nums[index,n)           当前位置可以选择的剩余元素
```

每层回答的问题是：

```text
排列的第index个位置放哪个剩余元素？
```

核心模板：

```java
for (int i = index; i < nums.length; i++) {
    swap(nums, index, i);       // 做选择
    process(nums, index + 1);   // 确定下一个位置
    swap(nums, index, i);       // 恢复父节点现场
}
```

回溯版的优点：

- 是“枚举所有选择”的通用模型，容易扩展约束和剪枝。
- 可以在构造过程中排除不合法前缀。
- 适合全排列、含重复值的去重排列、约束排列等问题。

回溯版默认不一定按字典序输出。是否具有字典序，取决于初始候选顺序和每层枚举顺序。

## 2. 基于 Q31 的字典序生成器

新增实现：
[《Q46_PermutationsByLexicographicOrder.java》](./Q46_PermutationsByLexicographicOrder.java)。

它不构造递归树，而是把全部排列当成一条有序链：

```java
Arrays.sort(current);
int[] first = current.clone();
do {
    collect(current);
    nextPermutation(current);
} while (!Arrays.equals(current, first));
```

两种生成器的复杂度数量级相同：

```text
结果数量：N!
每个结果的复制成本：O(N)
时间复杂度：O(N * N!)
返回结果空间：O(N * N!)
```

区别在于思考视角：

| 实现 | 思考视角 | 更适合的场景 |
|---|---|---|
| 回溯生成 | 当前位置从剩余候选中选谁 | 需要剪枝、局部约束、组合搜索 |
| 反复调用Q31 | 在字典序中不断访问直接后继 | 要求严格字典序输出、理解排列顺序 |

## 四、Q31：如何求字典序的“刚好大一点”

代码：[《Q31_NextPermutation.java》](./Q31_NextPermutation.java)。

## 1. 题目真正的约束

Q31不是要求任意一个更大排列，而是同时满足：

```text
1. 结果必须比当前排列大；
2. 在所有更大排列中，结果必须最小；
3. 原地修改，额外空间O(1)。
```

这句话等价于：

```text
寻找字典序中比当前排列刚好大一点的排列。
```

## 2. 为什么先从右向左找上升点

字典序比较时，越靠左的位置权重越大。为了让整体的增量尽可能小，应该尽量修改靠右的位置。

从右向左寻找第一个：

```text
nums[pivot] < nums[pivot + 1]
```

找到后，`pivot`右侧的后缀必然是非递增的：

```text
nums[pivot + 1] >= nums[pivot + 2] >= ... >= nums[n - 1]
```

这表示右侧后缀已经是固定当前前缀时能形成的最大排列。只在后缀内重排已经无法让整体变大，
所以必须增大`nums[pivot]`。

## 3. 为什么与右侧“最小的更大元素”交换

增大`pivot`是必须的，但不能增大过多。因此应该选择：

```text
右侧所有大于nums[pivot]的元素中，值最小的一个。
```

由于右侧后缀已经非递增，从最右侧向左找到的第一个大于`nums[pivot]`的元素，
就是值最小的合法后继。

注意必须使用严格大于：

```text
nums[successor] > nums[pivot]
```

如果允许交换相等值，整体排列可能没有真正变大。

## 4. 为什么最后只需要反转后缀

交换完成后，新前缀已经确保整体比原排列大。为了得到这个新前缀下的最小排列，
后缀必须升序。

原后缀是非递增的，交换最右合法元素后，剩余后缀仍然可以通过一次反转变为非递减序列。
因此不需要调用`Arrays.sort`，反转就是`O(N)`的最优操作。

## 5. 完整例子

```text
输入：[1,3,5,4,2]
```

1. 从右向左查找，最右上升点是`3`：

```text
[1, 3, 5, 4, 2]
    ^  --------
  pivot  非递增后缀
```

2. 从右向左找第一个大于3的数，得到4。
3. 交换3和4：

```text
[1,4,5,3,2]
```

4. 反转后缀`[5,3,2]`：

```text
[1,4,2,3,5]
```

这个结果比原排列大，且在所有更大排列中最小。

## 6. 已经是最大排列时

```text
[3,2,1]
```

整个数组都是非递增序列，找不到上升点，说明它已经是全局最大排列。
按题意需要回到最小排列，反转整个数组即可：

```text
[3,2,1] -> [1,2,3]
```

## 7. Q31 三句话记忆法

```text
1. 从右找最右上升点；
2. 用右侧最小的更大值替换它；
3. 后缀恢复成最小升序。
```

这三句的目标不是背代码，而是始终围绕：

```text
让整体变大，但增量尽可能小。
```

## 五、Q60：使用阶乘分块直接进行排名反解

代码：[《Q60_PermutationSequence.java》](./Q60_PermutationSequence.java)。

## 1. 为什么每个首元素占据`(n-1)!`个排列

对于`[1,2,3,4]`，固定首元素为1后，剩余`[2,3,4]`有`3! = 6`种排列。
因此全部`4! = 24`个排列可以分成4个相同大小的块：

```text
第 0 块：以1开头，包含排名[0, 5]
第 1 块：以2开头，包含排名[6,11]
第 2 块：以3开头，包含排名[12,17]
第 3 块：以4开头，包含排名[18,23]
```

对于0-based排名`rank`：

```text
rank / (n-1)! = 首位应该选剩余数字中的第几个
rank % (n-1)! = 进入该块后的新块内排名
```

选定首位并从候选集合中删除后，剩余问题完全相同，只是规模由`n`变成`n-1`。

## 2. `k--`是 Q60 最容易遗漏的边界

题目定义的`k`是1-based：

```text
第1个、第2个、...、第n!个
```

阶乘分块使用整除和取模，需要0-based排名：

```text
0、1、...、n!-1
```

所以必须先：

```java
int rank = k - 1;
```

例如每块大小为6时：

```text
1-based的第6个排列仍然在第一块；
0-based排名为5，5 / 6 = 0，正确。

如果不减1：6 / 6 = 1，会被错误分到第二块。
```

## 3. 完整例子：`n=4, k=9`

先转成0-based排名：

```text
rank = 9 - 1 = 8
available = [1,2,3,4]
```

| 剩余位数 | 每块大小 | 选择下标 | 选中数字 | 新块内排名 | 剩余数字 |
|---:|---:|---:|---:|---:|---|
| 4 | `3!=6` | `8/6=1` | 2 | `8%6=2` | `[1,3,4]` |
| 3 | `2!=2` | `2/2=1` | 3 | `2%2=0` | `[1,4]` |
| 2 | `1!=1` | `0/1=0` | 1 | `0%1=0` | `[4]` |
| 1 | `0!=1` | `0/1=0` | 4 | 0 | `[]` |

答案是：

```text
2314
```

## 4. 为什么面试中使用`ArrayList.remove(index)`就足够

选定一个数字后，需要把它从有序候选列表中删除。`ArrayList.remove(index)`需要移动后续元素，
所以总复杂度是：

```text
O(N^2)
```

本题保证`n <= 9`，`O(N^2)`只有几十次操作，已经足够。可以用 Fenwick 树支持第k个剩余数字查询，
把复杂度优化到`O(N log N)`，但在本题范围内属于不必要的实现复杂度。

## 六、三种模型的横向对比

| 题目/模型 | 输入 | 输出 | 核心操作 | 时间 | 额外空间（不含结果） |
|---|---|---|---|---:|---:|
| Q46 回溯全排列 | 元素集合 | 所有排列 | 递归树上选择当前位置 | `O(N*N!)` | `O(N)`递归栈 |
| Q46 字典序生成 | 元素集合 | 所有排列 | 从最小排列反复求直接后继 | `O(N*N!)` | `O(N)`工作副本 |
| Q31 下一个排列 | 一个排列 | 直接后继 | 最右上升点+最小增量+后缀最小化 | `O(N)` | `O(1)` |
| Q60 第k个排列 | `n,k` | 排名k对应的排列 | 阶乘分块反排名 | `O(N^2)` | `O(N)` |

最重要的区别：

```text
Q46必须访问所有N!个结果，因为题目要求输出全部结果。
Q31只向后移动一步，不需要知道当前的具体排名。
Q60只要一个结果，不能真的枚举k-1个中间排列。
```

## 七、含重复元素时会发生什么

## 1. 不重复排列数量不再是`N!`

如果总长度为`N`，其中各种元素的出现次数分别为`c1,c2,...`，则不重复排列数为：

```text
N! / (c1! * c2! * ...)
```

例如`[1,1,2]`：

```text
3! / 2! = 3

112
121
211
```

## 2. Q31 仍然正确

Q31的判断使用严格大小关系：

```text
上升点：nums[pivot] < nums[pivot+1]
后继元素：nums[successor] > nums[pivot]
```

它会直接跳到下一个不同的字典序排列，不会因为重复值产生额外重复状态。

## 3. 回溯全排列需要额外去重

如果直接把两个值相同但下标不同的元素分别选入，会产生相同结果。常见做法是：

```text
排序 + used[]：同一层跳过前一个相同且尚未使用的元素；
交换模型：每层使用Set记录已经放过的值。
```

这对应 Q47 全排列 II。

## 4. Q60 的简单阶乘分块不能直接照搬

Q60的标准题意是`[1,2,...,n]`，元素互不相同，所以每个首元素对应的块大小都是`(n-1)!`。

含重复值时，选择不同首元素后，剩余多重集的计数可能不同，需要为每个候选首元素单独计算：

```text
remaining! / (c1! * c2! * ...)
```

然后再判断排名落在哪个变长块中。

## 八、排列、组合、子集的边界

本专题只研究“排列”，即顺序会影响结果：

```text
[1,2]和[2,1]是两个不同排列。
```

与组合、子集的区别：

| 结构 | 顺序是否重要 | 是否必须使用全部元素 | 互异N元素结果数 |
|---|---|---|---:|
| 全排列 | 重要 | 是 | `N!` |
| k排列 | 重要 | 只使用k个 | `N!/(N-k)!` |
| k组合 | 不重要 | 只使用k个 | `N!/(k!(N-k)!)` |
| 子集 | 不重要 | 使用0..N个 | `2^N` |

更详细的回溯树对比见
[《全排列、子集、所有排列前缀与子字符串.md》](../Backtracking/全排列、子集、所有排列前缀与子字符串.md)。

## 十、总结：面试中应该记住什么

### Q46

```text
递归树每层确定一个位置；
数组交换改变了父状态，返回前必须交换恢复；
输入含重复值时需要同层去重。
```

### Q31

```text
目标是“整体变大，但增量最小”；
找最右上升点；
用右侧最小的更大值替换；
将后缀变成最小升序。
```

### Q60

```text
先将k从1-based转为0-based；
剩余remaining个数字时，每个候选首元素占据(remaining-1)!个排列；
商决定当前选第几个剩余数字，余数变成新块内排名。
```

把三道题放回同一个有序排列空间后，最终的统一结论是：

```text
Q46看全部；
Q31走一步；
Q60跳到第k步。
```
