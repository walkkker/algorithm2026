## 标记规则

这份文件集中记录需要独立完成的题目及其完成状态，是后续查询TODO题目的唯一总表。

代码文件使用统一标记：

```text
TODO: 【待独立完成-Codex新增】
```

当你独立写完并通过对数器或LeetCode验证后，应同时执行两项修改：

1. 将代码Javadoc中的TODO标记替换为`DONE: 【已独立完成】`。
2. 将本表对应行的状态改为“已完成”，并填写完成日期。

参考实现、标准模板和对数器本身不算“已独立完成”。只有你自己重新推导并写出核心算法后才修改状态。
