# 两个正序数组的中位数

对应题目：[Q4_MedianOfTwoSortedArrays.java](./Q4_MedianOfTwoSortedArrays.java)

## 核心结论

本题不是直接在两个数组中搜索某个元素，而是：

> 在两个有序数组中分别确定一条分割线，使左半部分包含较小的一半元素，右半部分包含较大的一半元素。

找到合法分割线后，中位数只由分割线旁边的四个元素决定。

```text
nums1:  [... aLeft | aRight ...]
nums2:  [... bLeft | bRight ...]
```

因为两个数组内部已经有序，所以只需要检查两个交叉条件：

```text
aLeft <= bRight
bLeft <= aRight
```

满足这两个条件，就能保证左半部分所有元素都不大于右半部分所有元素。

## 为什么只在短数组上二分

首先保证：

```text
m = nums1.length
n = nums2.length
m <= n
```

只二分短数组的分割位置，可以获得：

1. 时间复杂度为 `O(log(min(M,N)))`。
2. 由 `j = leftSize - i` 计算出的长数组分割位置始终处于 `[0,n]`。

如果 `nums1` 更长，交换两个数组后重新调用即可。交换最多发生一次。

## i 和 j 的准确含义

```java
int i = (l + r) / 2;
int j = leftSize - i;
```

`i` 不是某个元素的下标，而是：

> `nums1` 左半部分选择的元素数量，也就是 `nums1` 的分割位置。

因此它的合法范围是：

```text
0 <= i <= m
```

二分边界必须写成：

```java
int l = 0;
int r = m;
```

不能写成 `r = m - 1`，因为 `i == m` 表示 `nums1` 的所有元素都被分到左侧，这是一个合法分割位置。

两个数组左半部分的元素总数必须固定：

```text
i + j = leftSize
```

所以确定 `i` 后：

```java
int j = leftSize - i;
```

## leftSize 为什么加 1

```java
int leftSize = (m + n + 1) / 2;
```

偶数长度：

```text
总长度6：左边3个，右边3个
```

奇数长度：

```text
总长度5：左边3个，右边2个
```

加 `1` 的目的是让总长度为奇数时，中位数归入左半部分：

```text
leftSize = rightSize + 1
```

这样奇数情况下，中位数就是左半部分最大值。

## 分割线边界与哨兵

正常情况下：

```java
aLeft  = nums1[i - 1];
aRight = nums1[i];
bLeft  = nums2[j - 1];
bRight = nums2[j];
```

分割线可能位于数组最左或最右：

```text
i == 0：[ | nums1全部元素]
i == m：[nums1全部元素 | ]
```

为了统一比较逻辑，使用正负无穷哨兵：

```java
int aLeft = i == 0
        ? Integer.MIN_VALUE
        : nums1[i - 1];

int aRight = i == m
        ? Integer.MAX_VALUE
        : nums1[i];
```

`bLeft`、`bRight` 同理。哨兵没有真正加入数组，只用于表示分割线一侧没有元素。

## 二分方向

### aLeft > bRight

```text
nums1左侧选择的元素太多，aLeft太大。
```

需要减小 `i`：

```java
r = i - 1;
```

### bLeft > aRight

```text
nums1左侧选择的元素太少，aRight太小。
```

需要增大 `i`：

```java
l = i + 1;
```

记忆结论：

```text
aLeft太大：i向左
bLeft太大：i向右
```

## 如何计算中位数

找到合法分割线后：

```java
int maxLeft = Math.max(aLeft, bLeft);
```

总长度为奇数：

```text
左半部分比右半部分多一个元素
中位数 = maxLeft
```

总长度为偶数：

```java
左侧中间值 = max(aLeft, bLeft)
右侧中间值 = min(aRight, bRight)
中位数 = (maxLeft + minRight) / 2
```

两个 `int` 相加前必须先转换成 `double`，避免整数溢出：

```java
return ((double) maxLeft + minRight) / 2;
```

## 推演示例

```text
nums1 = [1,2]
nums2 = [3,4]
leftSize = 2
```

第一次分割：

```text
i = 1, j = 1

nums1: [1 | 2]
nums2: [3 | 4]

aLeft=1, aRight=2
bLeft=3, bRight=4
```

此时 `bLeft > aRight`，说明 `nums1` 左侧选少了，令 `i` 增大。

第二次分割：

```text
i = 2, j = 0

nums1: [1,2 | ]
nums2: [ | 3,4]

aLeft=2, aRight=+∞
bLeft=-∞, bRight=3
```

两个交叉条件成立，中位数为：

```text
(max(2,-∞) + min(+∞,3)) / 2
= (2 + 3) / 2
= 2.5
```

## 标准最优解

```java
class Solution {

    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // 保证nums1是短数组，在nums1上二分。
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = nums1.length;
        int n = nums2.length;
        int leftSize = (m + n + 1) / 2;

        // i表示nums1左半部分的元素数量，范围是[0,m]。
        int l = 0;
        int r = m;

        while (l <= r) {
            int i = (l + r) / 2;
            int j = leftSize - i;

            int aLeft = i == 0
                    ? Integer.MIN_VALUE
                    : nums1[i - 1];

            int aRight = i == m
                    ? Integer.MAX_VALUE
                    : nums1[i];

            int bLeft = j == 0
                    ? Integer.MIN_VALUE
                    : nums2[j - 1];

            int bRight = j == n
                    ? Integer.MAX_VALUE
                    : nums2[j];

            if (aLeft > bRight) {
                // nums1左侧选多了。
                r = i - 1;
            } else if (bLeft > aRight) {
                // nums1左侧选少了。
                l = i + 1;
            } else {
                int maxLeft = Math.max(aLeft, bLeft);

                if (((m + n) & 1) == 1) {
                    return maxLeft;
                }

                int minRight = Math.min(aRight, bRight);
                return ((double) maxLeft + minRight) / 2;
            }
        }

        // 题目保证数组有序且不会同时为空，正常不会到达这里。
        throw new IllegalArgumentException("输入数组必须保持有序");
    }
}
```

## 易错点

| 易错点 | 正确结论 |
|---|---|
| 把 `i` 当成元素下标 | `i` 是分割位置，也是左侧元素数量 |
| 二分范围写成 `[0,m-1]` | 必须是 `[0,m]` |
| 直接访问 `nums1[i-1]`、`nums1[i]` | 分割线位于边界时使用正负无穷哨兵 |
| 合法条件使用严格小于 | 数组允许重复值，必须使用 `<=` |
| 使用动态的 `mid == r` 判断数组末尾 | `r` 是搜索边界，不代表数组末尾 |
| 先执行两个 `int` 的加法 | 先转成 `double`，避免整数溢出 |

## 复杂度

```text
时间复杂度：O(log(min(M,N)))
额外空间复杂度：O(1)
```

参数交换使用的递归最多执行一次，可以视为常数额外空间。
