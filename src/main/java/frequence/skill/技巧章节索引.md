# Hot 100 技巧章节

## 章节定位

“技巧”不是一个统一的数据结构或算法模型，而是若干利用题目特殊条件，把问题转化为经典模型的题目集合。
做这组题时，首先检查值域、重复次数、是否允许修改数组和空间复杂度等限制，不要只记最终代码。

| 题目 | 核心转化 | 代码 |
|---|---|---|
| 136. 只出现一次的数字 | 成对元素异或抵消 | [Q136](./Q136_SingleNumber.java) |
| 169. 多数元素 | Boyer-Moore不同元素两两抵消 | [Q169](./Q169_MajorityElement.java) |
| 75. 颜色分类 | 荷兰国旗三区域划分 | [Q75](./Q75_SortColors.java) |
| 31. 下一个排列 | 字典序直接后继 | [Q31](../permutation/Q31_NextPermutation.java) |
| 287. 寻找重复数 | 数组映射函数图 + Floyd环入口 | [Q287](./Q287_FindTheDuplicateNumber.java) |

## 共同关注点

```text
Q136：先写异或公式，确认单位元必须是0。
Q169：题目保证多数元素存在，才可以省略候选值复验。
Q75：始终维护四段区间；与more区域交换后，index不能移动。
Q31：先找最右上升点，再找最小增量，最后把后缀恢复为最小排列。
Q287：值域可以作为下标，才能把下标映射为节点引用、nums[index]映射为next。
```

对数器见[SkillChapterDifferentialTest](./SkillChapterDifferentialTest.java)，五道题均包含确定性或随机基准验证。
