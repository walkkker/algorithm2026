# Q763：剩余频次与最后出现位置

## 核心共性

**当前段的所有字符都不能再出现在后缀中。一旦首次满足，就立即切分。**
这是最早合法切分点；在此切分不会产生跨段字符，也不会限制后缀的划分，所以能得到最多片段。

## 用户方法：反复检查 isClear

- `count[c-'a']`：未扫描后缀中字符c的剩余次数。
- `set`：当前段出现过的字符。
- `letters`：当前段长度。

每次读取字符后，先加入set并递减频次；isClear检查set中所有字符的剩余频次是否为0。满足时收集长度，重置长度并清空set。

固定26种小写字母，检查最多26项，时间O(26N)=O(N)，时间已经渐近最优。用户版本的toCharArray占O(N)额外空间；不能因频次数组只有26项就忽略字符数组。不计返回结果。

## 最后位置法：每个小写字母提出一个边界要求

`last`不是频次数组。26个槽分别对应a到z，槽中存放该字母在字符串中的**最后出现下标**。

```java
last[s.charAt(i) - 'a'] = i;
```

这里有两个不同下标：`字符-'a'`是26个字母的编码，`i`是字符在原字符串的位置。从左往右不断覆盖同一个字母的槽，最后保留的自然是该字母的最后位置。

例如 `s="abac"`：

| 字母 | 槽下标 | 最后位置 |
| --- | --- | --- |
| a | 0 | 2 |
| b | 1 | 1 |
| c | 2 | 3 |

遇到a，当前段至少延伸到2；再遇到b，只要求延伸到1，不能把原来的边界2缩回1。因此必须写：

```java
end = Math.max(end, last[s.charAt(i) - 'a']);
```

走到i=2时，当前段中的a和b都不再出现在后面，收集长度3。随后c自成一段，结果为[3,1]。

若扫描过程中遇到一个最后位置更远的新字符，就继续扩展end；必须扫描扩展后的区间，新区间里的字符也可能进一步扩大边界。

## 两种方法为什么等价

对于当前段已出现字符c，在扫描完i之后：

```text
剩余频次count[c]==0  等价于  last[c]<=i
```

所有字符都满足，等价于它们的last最大值不超过i。该最大值包含当前字符的last，必然不小于i，因此切分条件恰好是 `i == end`。

最后位置法时间O(N)、额外空间O(1)，使用charAt，不复制整个字符串。不计返回结果。

**复盘重点：把“反复检查所有条件是否满足”转成“维护所有条件共同要求的最远边界”。**
