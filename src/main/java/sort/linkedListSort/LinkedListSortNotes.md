# 链表排序练习笔记

## 统一模型

链表排序不依赖随机访问，核心操作是节点重组：

```text
保存后继 -> 当前节点断链 -> 放入目标位置或分区 -> 继续处理原后继
```

修改指针前必须先保存：

```java
Node next = cur.next;
```

单链表连接只维护 `next`，独立区间必须满足 `tail.next == null`；双向链表连接必须同时维护 `next` 和 `last`，独立区间还应满足：

```text
head.last == null
tail.next == null
```

## 数组算法映射到链表

核心抽象：数组通过下标表达递归子问题的边界；链表通过断链、头尾节点或节点数量表达递归子问题的边界。

| 数组 | 链表 |
|---|---|
| `arr[l...r]` | 从 `head` 到 `null` 的独立链表 |
| `l、r` | `head、tail` 或 `head、size` |
| `mid` | 快慢指针找到的中点 |
| `[l,mid]` 与 `[mid+1,r]` | 断开后的左右子链表 |
| `r - l + 1` | 链表节点数量 `size` |
| 移动数组元素 | 修改节点的 `next/last` |
| 归并使用 `help[]` | 归并时重新连接原节点 |
| 子区间起点始终是 `l` | 排序后头节点可能变化，必须返回新 `head` |

数组不需要真的切开，因为 `l、r` 已经限制了递归范围；链表没有下标，不断链就可能沿着 `next` 进入另一个子问题。因此链表递归通常先把当前范围变成以 `null` 结尾的独立链表。

```text
数组递归：边界由参数约束。
链表递归：边界由结构约束。
```

归并排序的映射：数组通过 `mid` 得到两个下标区间；链表通过快慢指针找到中点并执行 `slow.next = null`，得到两条独立链表。

快速排序的映射：数组通过荷兰国旗下标划分小于区、等于区和大于区；链表把节点逐个摘除并重新组成 `less/equal/more` 三条独立链表。

链表也可以通过 `process(head, tail)` 保留物理连接，但每次遍历都必须额外判断 `tail` 边界。面试实现中主动断链通常更容易维护递归契约和避免跨区间遍历。

迁移数组算法到链表时，先识别原算法依赖的下标边界，再决定使用断链、`head/tail` 或 `head/size` 表达同一个子问题。

## 三种排序

| 练习 | 已维护结构 | 当前节点的处理方式 | 复杂度 |
|---|---|---|---|
| 单链表插入排序 | 有序前缀 | 在有序前缀中寻找前驱并插入 | `O(N^2)` 时间，`O(1)` 额外空间 |
| 单链表归并排序 | 两个有序子链表 | 比较两个头节点并依次接入结果链表 | `O(N log N)` 时间，递归栈 `O(log N)` |
| 双向链表随机快排 | `< pivot`、`== pivot`、`> pivot` 三个分区 | 节点断链后追加到对应分区 | 期望 `O(N log N)`，最坏 `O(N^2)` |

## 解题骨架

### 插入排序

外层遍历未排序节点；内层从哨兵节点开始，在有序链表中寻找最后一个 `<= cur.value` 的节点，然后插入。当前节点值不单调，因此查找指针通常不能跨轮次复用。

### 归并排序

使用快慢指针找到中点并断链；递归排序左右链表；最后合并两个有序链表。链表排序题优先考虑归并排序。

递归函数应定义为：`sort(head)` 接收一条以 `head` 开始、以 `null` 结束的独立链表，返回排序后的新头节点。链表排序后头节点可能变化，父递归必须使用返回值接住：

```java
Node left = sort(leftHead);
Node right = sort(rightHead);
return merge(left, right);
```

不需要向递归函数传入子链表的原前驱节点。递归前执行 `slow.next = null`，让左右区域成为两条独立链表；递归后由父函数的 `left/right` 变量接住新头，再通过 `merge` 完成当前范围的连接。

```text
数组归并：依靠固定下标表示子区间，排序后区间起点不变。
链表归并：依靠断链表示子区间，通过返回值传递排序后的新头。
```

链表归并直接复用原节点并修改 `next`，不需要数组归并中的 `help[]`。标准迭代合并过程只使用常数个指针，因此自顶向下递归版本的额外空间主要来自 `O(log N)` 递归栈；自底向上迭代版本可以做到 `O(1)` 额外空间。如果合并过程递归实现，或者为每个值创建新节点，则额外空间可能退化为 `O(N)`。

### 双向链表快排

随机选择并摘除 pivot；遍历剩余节点并完成三向分区；递归排序小于区和大于区；最后按照“小于区、等于区、大于区”拼接。递归结果应同时返回 `head` 和 `tail`。

## 对数器与对拍

- **对数器**：随机数据生成、参考排序、待测排序和结构校验组成的测试程序。
- **对拍**：使用对数器，让待测实现与参考实现处理相同输入并比较结果。
- 单链表需要检查：升序、节点数量、是否成环。
- 双向链表还需要检查：`next.last`、`last.next` 和反向遍历结果。
