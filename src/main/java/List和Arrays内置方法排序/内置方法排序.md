**List 排序**

```java
list.sort((a, b) -> Integer.compare(a, b));
```

升序：

```java
list.sort((a, b) -> Integer.compare(a, b));
```

降序：

```java
list.sort((a, b) -> Integer.compare(b, a));
```

也可以：

```java
Collections.sort(list, (a, b) -> Integer.compare(a, b));
```

**数组排序**

对象数组支持 Lambda：

```java
Integer[] arr = {3, 1, 2};

Arrays.sort(arr, (a, b) -> Integer.compare(a, b));
```

二维数组按第一列升序：【注意这里，因为对于二维数组，int[]是元素，所以也算是对象】

```java
Arrays.sort(arr, (a, b) -> Integer.compare(a[0], b[0]));
```

按第一列升序、第二列降序：

```java
Arrays.sort(arr, (a, b) ->
        a[0] != b[0]
                ? Integer.compare(a[0], b[0])
                : Integer.compare(b[1], a[1])
);
```

补充：关键在于 people 的类型是 int[][]，它在 Java 中被称为“数组的数组”。
- 虽然最外层是基本类型 int[] 组成的数组，但 a 和 b 代表的是里面的每一个元素，也就是内部的那个 int[]（一个长度为 2 的整型数组）。
- 在 Java 中，数组是对象，即使它里面装的是基本类型 int。
- 既然 a 和 b 是对象（类型为 int[]），那么它们就可以调用 .equals() 等方法，也完全可以作为 Lambda 表达式 (a, b) -> ... 的参数，并且可以通过 a[0]、a[1] 来访问其内部的元素。




基本类型数组不支持比较器：

```java
int[] arr = {3, 1, 2};
Arrays.sort(arr);
```

注意：比较器不要直接写 `a - b`，可能整数溢出；使用 `Integer.compare(a, b)`。

### 那基本类型逆序怎么搞？

Java 基本类型数组不支持 Comparator。先升序排序，再原地反转：

```java
int[] arr = {3, 1, 2};

Arrays.sort(arr);

for (int l = 0, r = arr.length - 1; l < r; l++, r--) {
    int temp = arr[l];
    arr[l] = arr[r];
    arr[r] = temp;
}
```

结果：

```text
[3, 2, 1]
```

也可以装箱，但有额外开销：

```java
Integer[] arr = {3, 1, 2};
Arrays.sort(arr, (a, b) -> Integer.compare(b, a));
```

面试中推荐：

```text
int[]：Arrays.sort + 原地反转
Integer[]：Lambda 比较器
```
