## 总结
1.  ^ 等同于 无进位相加:
- a ^ a = 0
- a ^ 0 = a
2. 这里使用位运算都是要遍历数组本身的，所以时间复杂度O(N)没有优化。
   - 但是基于位运算的最优解，可以优化 额外空间复杂度，从O(N) 优化到O(1)。 这是位运算的价值，优化空间复杂度

1. 仅用位运算交换数组中的两个位置的数字
2. [arr中，只有一种数，出现奇数次](EvenTimesOddTimes.java): eor^ 对 奇偶数很敏感
