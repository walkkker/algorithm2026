## 重点
1. indexTree与线段树一样，从index=1开始。 支持 单点新增，前缀和 O(logN)
   1. 可以扩展为单点更新 -> **数据结构内部多一个数组记录最新的元素值，记得初始时为0，然后依次调用update方法更新+tree数组记录信息** ，可以将更新操作转换为新增操作  (1) int add = new_value - arr[i] (2) arr[i] = new_value
2. 逻辑很简单：假设index为原数组中的位置 （add方法是不断加最右侧的1，preSum是不断减最右侧的1）
   1. 添加值：for (i = index + 1; i <= origin.length; i += (i & -i) )  {tree[i] += add}
   2. 计算前缀和: for (i = index + 1; i > 0这里注意; i -= (i & -i)) {ans += tree[i]}
3. 2D indexTree（indexTree求二维数组 区域和）：线段树全部可以实现1D index tree的功能。但是indexTree可以很快速的 扩展到2D。
    - 对于arr[i][j] 的 int add。 所有 i+1往后 * j+1往后 的组合
    - 对于左上角为(0,0) 右下角为(i,j)的矩形（等同于前缀和）。 所有i+1往前 * 所有j+1往前 的组合。
4. 【特别重要的纠错点-2D代码】我们每次聊坐标，但是一定要清楚->在一/二维数组中，坐标对应的是【格子】，而不是线交叉的点。！！！
